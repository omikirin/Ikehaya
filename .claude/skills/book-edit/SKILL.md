# /book-edit — 校正・推敲

## 手順

対象 `publishing/books/<slug>/manuscript/*.md` を全章、次の3パスで直接修正する。

### パス1: 構成
- 章間の重複・矛盾、outline との乖離
- 各章の「掴み→本論→まとめ」が成立しているか
- 長すぎる章の分割・短すぎる章の統合提案(実施はユーザー承認後)

### パス2: 文章
- 誤字脱字、係り受け、冗長表現(「することができる」→「できる」等)
- 一文60字超の分割、同語尾3連続の解消
- 表記統一: 数字は半角、英字は半角、「頂く/いただく」等のゆらぎを頻度多数派に寄せる

### パス3: リスク
- 断定できない効果効能・投資リターン等の表現を弱める
- 実在の人物・企業への言及で問題になりうる箇所
- 引用の出典漏れ

## 出力
1. 修正は原稿に直接適用する(大きな構成変更のみ提案止まり)。
2. `publishing/books/<slug>/edit_report.md` に章ごとの修正サマリと残課題を書く。
3. 最後に `python3 publishing/scripts/validate.py publishing/books/<slug>` を実行し結果を報告、/book-build を案内する。
