# /book-plan — 企画・構成

## 手順

1. **ヒアリング**: テーマ・想定読者・著者の強み(実体験/実績)を確認。足りなければ AskUserQuestion で1回だけまとめて聞く。
2. **書籍ディレクトリ作成**: `publishing/books/_template` を `publishing/books/<slug>` にコピー(slugは英小文字ハイフン)。
3. **企画立案**: 以下を `outline.md` に書く。
   - 読者ターゲット(具体的な1人まで絞る)
   - 読了後ベネフィット1行
   - タイトル案3つ以上(数字・ベネフィット・意外性のいずれかを含める)
   - 章構成(00_はじめに 〜 99_おわりに、各章の狙い1行付き)
   - 類書と差別化
4. **メタ確定**: `book.yaml` の title/author/description/keywords/categories/price_jpy を埋める。keywordsは検索されそうな語7つ。
5. **原稿ファイルの空枠作成**: 章構成に合わせて `manuscript/NN_slug.md` を見出しだけ入れて作る。

## 品質基準
- タイトルは13〜30字。読者の得が3秒で伝わること。
- 章は5〜10章。1章 3,000〜8,000字を想定した粒度に切る。
- description は「悩み提示→本書の約束→章内容チラ見せ→著者の信頼根拠」の順で200字以上。

完了したら章構成一覧を提示し、ユーザーの承認後に /book-write へ進むよう案内する。
