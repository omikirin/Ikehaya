# /book-write — 執筆

## 前提
対象は `publishing/books/<slug>/`。book.yaml と outline.md が確定していること(なければ /book-plan へ戻す)。

## 手順

1. `manuscript/` を見て未執筆(見出しのみ・テンプレ文言あり)の章を特定し、番号順に書く。
2. 1章の型:
   - 冒頭: 読者の悩み・あるあるで掴む(3〜5行)
   - 本論: 主張→理由→具体例(著者の実体験を最優先)→反論処理
   - 末尾: 章まとめ + 次章への橋渡し1行
3. 分量は outline の想定(既定 3,000〜8,000字/章)。
4. 書き終えるごとにファイル保存し、章タイトル・文字数を報告。

## 文体ルール
- です・ます調で統一。一文は60字以内目安。
- 段落は3〜5行で改行。スマホ読みを前提にする。
- 見出しは `#` を章題1つ、`##` を節に。節は1章に2〜5個。
- 抽象論だけの段落を作らない。必ず具体例か数字を入れる。
- 他書・他人の文章のコピーは禁止。引用は `>` で出典明記。

複数章を頼まれたら順に書き切る。全章完了したら総文字数を報告し /book-edit を案内する。
