# ネーム 第2話 描けない日の三色団子(全8ページ)

## P1
- コマ1 / のれんの下からひよこ(ピヨチ)が入ってくる / 効果音: ぴょこ
- コマ2 / 続いてうさぎ(ウサピ) / 効果音: ぴょん
- コマ3 / 最後にのっそり入るネム、餡音の困惑顔 / 餡音「いらっしゃ……い?」

## P2
- コマ1 / 縁台の端に座るネム、両脇に二匹 / ネム「団子。あるだけ」
- コマ2 / 三色団子を焼く餡音 / 餡音「あるだけは売れないなあ」
- コマ3 / 三色団子のアップ(桃・白・緑) / (ナレ)「串の上に春が三段」

## P3
- コマ1 / 食べながら自分の右手を見つめるネム / 演出: 視線の流れを強調
- コマ2 / 餡音、焼き台越しに / 餡音「筆、折れた?」ネム「折れてない」
- コマ3 / うつむくネム / ネム「何を描いても、前のやつの真似みたいになる」

## P4
- コマ1 / 頬をふくらませ黙るネム、二匹が見上げる / 効果音: もぐ…
- コマ2 / 古い品書きの板を持ってくる餡音 / 餡音「これ、描き直してくんない?」
- コマ3 / 板の芋みたいな団子の絵アップ / ネム「……ほんとだ。芋だ」 餡音「代金は団子で」

## P5
- コマ1 / 筆を構えるが穂先が止まるネム / 演出: 板の上で静止する筆
- コマ2 / 焦らず新しい串を焼く餡音 / 効果音: じゅう、ぱちっ
- コマ3 / 揺れる暖簾の影、店の空気の描写 / (ナレ)「餡音は焦らさなかった」

## P6
- コマ1 / 餡音、串を掲げて / 餡音「三色はね、『焼ける前と、焼けてるとこと、食べたあと』」
- コマ2 / 呆れ顔のネム / ネム「適当を言うな」
- コマ3 / 真剣な顔の餡音 / 餡音「団子屋の適当は、絵師の写生と同じくらい真剣だよ」

## P7
- コマ1 / 焼き台前で跳ねるピヨチ、湯気の向こうのウサピの耳 / 演出: 生きて動くものの躍動
- コマ2 / 筆が降りる瞬間の大ゴマ / 効果音: すっ…
- コマ3 / 泳ぐ筆、描かれていく団子と二匹 / 効果音: さらさら

## P8
- コマ1 / 完成した品書きを掲げるネム / ネム「……描けた」
- コマ2 / 満腹の二匹を抱えて帰るネムの後ろ姿、夕暮れ / なし
- コマ3 / 行灯の下、品書きの隅の似顔絵に気づく餡音 / 餡音「……あたし、こんな顔で焼いてんの」 / 演出: 頬に赤み、ひとりの店内
