# ネーム 第3話 猫又とみたらしの約束(全8ページ)

## P1
- コマ1 / のれんを跳ね上げて仁王立ちの猫又 / 猫又「甘いものは、苦手だ」
- コマ2 / きょとんとする餡音 / 餡音「じゃ、なんで団子屋に?」
- コマ3 / 目を逸らす猫又、外は快晴 / 猫又「……雨宿りだ」 / 演出: 窓の外にピーカンの空

## P2
- コマ1 / 茶だけ出す餡音、にやり / なし
- コマ2 / みたらし団子を焼き台に並べる / 効果音: じゅっ
- コマ3 / 猫又の耳がぴくりと動くアップ / 効果音: ぴくっ

## P3
- コマ1 / 湯呑みと睨み合う猫又 / 猫又「……そのたれ、醤油か」
- コマ2 / 絞り出す猫又 / 猫又「一本だけなら、付き合ってやらんこともない」
- コマ3 / 一口→目を見開く→「もう一本」の三連小コマ / 効果音: かぷ、カッ!! / 演出: 看板が焦げ落ちる比喩絵

## P4
- コマ1 / 皿の団子が一本消えている / 効果音: すっ… / 演出: 猫又は素知らぬ顔で茶
- コマ2 / もう一本消える / 餡音の目が細くなる
- コマ3 / 餡音、印を結ぶ / 餡音「あたしは影縫いの術なら知ってるんだ」

## P5
- コマ1 / 影に串を投げ打つ大ゴマ / 効果音: しゅっ、ずばっ
- コマ2 / 店の隅、団子をくわえたまま影を縫われた分身猫又 / 分身「にゃっ」
- コマ3 / 観念する本体 / 猫又「分身の食った分は、俺の腹に入らんのだ」 餡音「勘定には入ります」

## P6
- コマ1 / 小コマ・本体と分身が並んでみたらしを食べる / (ナレ)「奇妙な眺めだが、悪い眺めではなかった」
- コマ2 / 小コマ・猫又、串を咥えたまま / 猫又「甘いものが苦手な忍者は、変か」
- コマ3 / 小コマ・遠くを見る猫又 / 猫又「里では『魚の猫又』で通ってるんでな」
- コマ4 / 小コマ・たれを塗る餡音の手元だけ / 演出: 間(T-2)
- コマ5 / やや大きめ・餡音の横顔 / 餡音「役どころって、着たまま寝ると肩が凝るよ」 / 効果音: ぱたり(尻尾が縁台を打つ) / 演出: 会話劇の密ページ(K-4)

## P7
- コマ1 / 帰ってきた紫苑、尻尾を発見して固まる / 演出: 一歩ずつにじり寄る点線
- コマ2 / 尻尾のいちばん近くの縁台にすとんと座る紫苑、頬に満足の赤み / 効果音: すとん / 演出: ナレ不要、点線のにじり寄り→着地の絵だけで「猫好きの勝ち」を見せる(T-1)
- コマ3 / 猫又「魚はやらんのか」餡音「釣ってきたら焦がし醤油、塗ったげる」 / 猫又「……通いになるな」

## P8
- コマ1 / 分身の分まできっちり銭を置く猫又の手元 / 効果音: ちゃりん
- コマ2 / のれん前 / 猫又「今度、久遠を連れてくる」 餡音「分身さんもどうぞ」 猫又「もう出さん」
- コマ3 / 夕方、たれを多めに仕込む餡音の笑顔 / (ナレ)「通いになる、と客が言ったからである」
- コマ4 / 小コマ・壺を混ぜる手が少しゆっくりになる手元アップ / (ナレ)「『陽気な店主』という役どころのことは、考えないでおいた」 / 演出: 笑顔は見せず手元のみ、第4話ラストへの縦糸
