# ネーム 第4話 閃光刀は団子を切らない(全8ページ)

- コマ3 / ようやく縁台に座る断 / 断「任務の帰りに通りかかった。……ついでだ」

## P2
- コマ1 / 団子を二本出す餡音 / 断「一本と言った」 餡音「焼きすぎたの」
- コマ2 / 水平に構えた串を等速三口で食べる断 / 効果音: すっ、すっ、すっ / 演出: 任務報告のような食べ方
- コマ3 / 二本目に伸ばした手が止まる / 断「……妙なことを聞くが」

## P3
- コマ1 / 真顔の断アップ / 断「休みの日というのは、何をすればいい」
- コマ2 / 茶を注ぐ手が止まる餡音 / 演出: 間
- コマ3 / 断の説明 / 断「アトザ様に『休め』と命じられた。だが休むという任務の遂行の仕方が分からん」

## P4
- コマ1 / 問答 / 餡音「前の休みは?」断「巡回路の見直し」餡音「それ、仕事」
- コマ2 / 問答続き / 断「素振りを半分に」餡音「半分にしても素振りは素振り」
- コマ3 / 眉間に皺の断、湯呑みの前で立ち往生 / (ナレ)「悩みにも焼き加減がある」

## P5
- コマ1 / 餡音、二本目を指して / 餡音「その串、食べ方だけあたしに預けて」

- コマ3 / 炭のはぜる音、揺れる暖簾の影 / 効果音: ぱちり

## P6
- コマ1 / 一個ずつ、間のあるコマ割りで食べる断(3小コマ) / 効果音: …… / 演出: コマの余白で時間の減速を表現

- コマ3 / 餡音「休みは『長い串』。閃光刀で一気に切るのがいちばん駄目なやつ」

## P7
- コマ1 / 断の逆襲 / 断「店主は、いつ休む」餡音「店が休みの日……翌日の仕込み——あ」

- コマ3 / 湯呑みを掲げ降参する餡音 / 餡音「今度の店休み、あたしも長い串をやるよ」

## P8
