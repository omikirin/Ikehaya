# ネーム 第5話 凪紗の声とよもぎ団子(全8ページ)

## P1
- コマ1 / 気づけば影の席にちょこんと座っている凪紗 / (ナレ)「いつから店にいたのか、分からなかった」
- コマ2 / 餡音「いらっしゃい」/ 効果音: びくっ(凪紗の肩)
- コマ3 / 唇が動くが音が出ない凪紗、深くうつむく / 演出: 空白の吹き出し

## P2
- コマ1 / 大声で聞き返さず、矢立と紙を置く餡音の手元 / 効果音: ことり
- コマ2 / 餡音「うち、筆談注文もやってるんだ」 / (ナレ)「その制度は、たったいま生まれた」
- コマ3 / 肩の力が抜ける凪紗、さらさらと書く / 『よもぎだんご ひとつ』 / 演出: 細く綺麗な文字

## P3
- コマ1 / 小コマ・餡音「お茶は熱いの? ぬるいの?」
- コマ2 / 小コマ・筆談の返事 / 『ぬるいの』 餡音「通だねえ」
- コマ3 / 小コマ・よもぎを摘む朝の土手の回想 / 餡音「いい仕事は朝が勝負でしょ」
- コマ4 / やや大きめ・凪紗の筆談 / 『このみせ しってた。だんごのにおいだけ おぼえてた』 / 演出: 筆談の応酬は小コマで刻む密ページ(K-4)

## P4
- コマ1 / 筆が止まる / 『こえを かけるのが にがて』
- コマ2 / 値段表を直すふりで間を作る餡音 / (ナレ)「急いで励ますのは、熱すぎる茶を出すようなもの」
- コマ3 / 餡音、振り向いて笑顔 / 餡音「今日は寄れたんだから、上々だね」

## P5
- コマ1 / 焼く間、倍しゃべる餡音(よもぎ・芋の品書き・猫の客) / 効果音: ぺらぺら
- コマ2 / 下を向いたまま肩を揺らして笑う凪紗 / 効果音: ふるふる
- コマ3 / 大事に団子を食べる凪紗 / 演出: ゆっくりの間

## P6
- コマ1 / 凪紗の筆談 / 『たくさんしゃべるの つかれない?』
- コマ2 / 隣に座る餡音 / 餡音「疲れるよ、たまにね」 / 演出: 初めて目が合う
- コマ3 / 餡音「あたしが影を縫うみたいに、凪紗さんは音を縫ってるんだよ」

## P7
- コマ1 / 餡音、声を落として / 餡音「声が小さい人の『おいしい』は、百人前くらい効くからね」
- コマ2 / よもぎ団子より赤くなる凪紗の耳 / 効果音: ぽっ
- コマ3 / 紫苑と凪紗、会釈だけ交わして同じ静けさに座る / (ナレ)「静けさで居心地を作る術も、確かにある」

## P8
- コマ1 / のれんの手前で立ち止まり、息を吸う凪紗 / 効果音: すぅ…
