# ネーム 第6話 十六団子の日(全10ページ)

## P1
- コマ1 / 三月十六日の朝、蒸籠三段・たれ二壺の忙しい厨 / (ナレ)「餡音は自分の誕生日を忘れていた」
- コマ2 / 壁の羽目板が外れ、巨大な顔が覗く / 効果音: めきっ
- コマ3 / 悲鳴を上げる餡音 / 餡音「ぎゃあ!」 アウン「すまん。棚の修理を頼まれた」

## P2
- コマ1 / 体を縮めて棚に向かうアウンの大きな背中 / 効果音: こつ、こつ
- コマ2 / 慎重な金槌の手元アップ / アウン「力の加減が、苦手でな」
- コマ3 / アウンの独白 / アウン「割ったものの数は全部覚えている。覚えていれば、詫びられる」

## P3(左ページ)
- コマ1 / 焼き台前の餡音、背中越しに / 餡音「加減しようとしてる時点で、もう優しいんだよ」
- コマ2 / 小コマ・金槌が一拍止まる / 効果音: … / 演出: 間(T-2)
- コマ3 / 左ページ最終コマ=引き(K-1): 棚が直る/のれんがふわりと持ち上がる、その裾の外に複数の足音の影 / 効果音: ふわり / 演出: のれんの向こうを見せない

## P4(めくり直後・右ページ)
- コマ1 / 1ページ大ゴマ・全員集合の「見せ」(K-1): のれんをくぐる咲耶(粉の包み)を先頭に、ピヨチ・ウサピ・ネム(画板)、猫又、断が続々。のれんの陰から半分だけ顔を出す凪紗 / 咲耶「約束どおり、来た」 / 演出: 本話最大のサプライズをめくり直後に置く

## P5
- コマ1 / 小コマ・うろたえる餡音 / 餡音「え、今日なんかあった?」
- コマ2 / 小コマ・すまし顔の断 / 断「休みの教練の、実地演習だ」
- コマ3 / 小コマ・餡音、全員を見回す / 演出: 間
- コマ4 / やや大きめ・凪紗が巻物を広げる / 『三月十六日 十六だんごの日。あつまってください。だんごを十六こ、いっしょにたべます』
- コマ5 / 小コマ・巻物の端、署名のない余白 / (ナレ)「差出人の名はないが、密偵の仕事は署名をしないものだ」 / 演出: 大ゴマ後の刻みで密度の波を作る(K-4)

## P6
- コマ1 / 小コマ・駆け込んでくる紫苑、腕いっぱいの野の花 / 効果音: たたたっ
- コマ2 / 小コマ・息を吸う紫苑、無言 / 演出: 間(T-2)
- コマ3 / 人見知りを忘れて叫ぶ紫苑の大ゴマ(第二の山) / 紫苑「餡音、誕生日、おめでとう!」
- コマ4 / 泣き笑いになりかける餡音 / 餡音「あんたたち、営業は……」 断「貸し切りだ。手配済みだ」

## P7
- コマ1 / 横長コマ・厨の手前側: 手前で咲耶が粉を練り、その隣でネムが丸め、画板は縁台に立てかけ / 効果音: わいわい
- コマ2 / 横長コマ・厨の奥側: 奥で体を縮めたアウンが慎重に丸め(P2の手元と同じ慎重さ)、その手前で断が串に等間隔で刺す / 効果音: こつ、すっ
- コマ3 / 小コマ・味見しすぎの分身猫又が本体に叱られる、分身の手は枠外から / 猫又「こら!」 分身「にゃ」
- コマ4 / 小コマ・店先: 紫苑が花を飾り、凪紗が音もなく茶を淹れる / 効果音: (静) / 演出: 群像は3面に分割し各コマ2〜3人まで(作画可能性対応)

## P8

- コマ3 / 凪紗が指す壁の張り紙 / 『いつかだれかと十六個たべる』 / 演出: 餡音の目の見開き

## P9

- コマ3 / 咲耶に手を引かれ、客側の縁台に座る餡音 / (ナレ)「生まれて初めて、自分の店に客として座った」

## P10
- コマ1 / 焼き台じゃない側から見た店の全景、壁にネムの品書きと似顔絵 / (ナレ)「店は少し広く、ずいぶんあたたかかった」
