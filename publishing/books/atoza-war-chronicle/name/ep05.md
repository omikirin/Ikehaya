# 第五話 黄泉平坂(全10ページ)

## P1
- 1/大ゴマ・黄泉平坂の全景。縦に裂けた山肌、色のない闇、朽ちた注連縄と要石二つ/ゴ……
- 2/モノローグ「峠というより、傷だった。かつて誰かが、ここで同じ戦をしたのだろう」

## P2
- 1/軍議・岩爺の数珠が板図をなぞる/「要石は三つ。結ぶ間、術者は裂け目の縁で無防備じゃ」
- 2/アトザ、石を置く/「逢魔刻で境界を固定し、漆黒で要石を敵の目から消す」
- 3/岩爺笑う「年寄りの命は安い」/アトザ即答「安くない。あんたも連れて帰る数のうちだ」/岩爺の一瞬の真顔

## P3
- 1/夕刻・斜面に展開する連合軍の俯瞰/旗・風見二本
- 2/前衛の断と若手三人/中央のアウン・深く静かな呼吸/高所の呂屯
- 3/アトザ、静かな声/「功を数えるな。生きて隣に立っている仲間の数を数えろ」
- 4/小コマの刻み・結印を待つ甲賀術者の手元(印を組みかけて静止)/傾く陽の小コマ/演出: 見開き前の溜め(K-2)、コマを細かく刻んでからP4へ

## P4(見開き前半・術発動)
- 1/大ゴマ・陽が山の端にかかる。世界が灰と橙に沈む/「逢魔刻」/画面全体のトーン変化・時が淀む演出

## P5(見開き後半)
- 1/大ゴマ・数珠が鳴り、戦場が漆黒に呑まれる/「幻術——漆黒」/ジャアッ/黒ベタ大胆に
- 2/闇の中で同士討ちを始める影の軍勢/ギシャアア

## P6
- 1/アトザの視界の縁が白く欠ける主観コマ/モノローグ「体温が、滝のように抜ける」
- 2/甲賀の術者たち・折れた要石を立て直し結印/カッ(一つ目の光)
- 3/断の閃光が闇に三度瞬く/カッカッカッ

## P7
- 1/結印二つ目の光/カッ/「残る要石、一つ!」
- 2/闇の中心から歩いてくる虚・ただ一人/ヒタ…ヒタ…
- 3/漆黒の中を迷いなく真っ直ぐアトザへ/『将よ。おまえにだけは、見せてやろう』

## P8
- 1/虚の輪郭がほどける/ズル…
- 2/大ゴマ・淀んだ時の中に立つ死者たち五人。配置: 斜面の上方に横一列の半円、中央に一番若い顔、その左右に谷の三人、端に二番組の一人。全員がアトザより高い位置に立ち、カメラはアトザ背中越しのフカン気味=見上げる構図でアトザを孤立させる(K-5)/しん……
