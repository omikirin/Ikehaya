# 公式設定要約(出典: NINJAMCP get_character / get_worldview)

## アウン(Aum / #029)主役
- クラン: 風魔
- 忍術: 巨人の一撃(A Titan's Blow)— 自らの体を巨大化させる力
- 武器: 棍棒(Club)
- 誕生日: 5月9日(「呼吸の日」にちなむ)
- プロフィール: アトザの弟であり、自らの体を巨大化させる力を持つ。
- 関係: アトザ(#013)の兄弟(弟)。

## アトザ(Atoza / #013)
- クラン: 風魔(首領格)
- 忍術: 逢魔刻(Time for Disasters)
- 武器: 棍棒(Club)
- 誕生日: 11月2日(「いい鬼の日」にちなむ)
- プロフィール: 風魔クランを率いる首領格でありながら、実際は情に厚い一面を持つ。
- 関係: アウン(#029)の兄。呂屯(#007)・断(#010)を部下に持つ。シーズン1で岩爺(#016)たちと共に根の国を封印した。

## 世界観(要点)
- シーズン2(現代)は平和な時代。4クラン(伊賀・甲賀・風魔・雑賀)に大きな対立はなく、忍者は鬼や悪霊の退治、里のトラブル解決を担う。
- シーズン1でアトザは岩爺たちと根の国を封印。シーズン3で根の国とのパスが開く構想。
- 風魔メンバー: 狐白・呂屯・断・アトザ・蛇ノ目・カルマ・アウン・イブキ。
