# ネーム 第1話 月夜の帳簿(全8ページ)

## P1
- 1/雑賀の里の夜景・俯瞰。月と堀/―/効果音:シーン
- 2/行灯の灯る一軒。膝に三味線、撥を構える弁天の影/―/効果音:(無音)/演出:灯りだけ暖色
- 3/構えたまま止まる撥のアップ。そして下ろす/弁天M「里は眠ってる。……いつもの、言い訳だ」/効果音:スッ

## P2
- 1/撥を算盤に持ち替え、帳簿の山へ/弁天M「米蔵、普請、礼状……」/効果音:サラ(筆)
- 2/文机の脇に戻された三味線のアップ/―/演出:埃うっすら
- 3/胸元に手。イメージ:張りつめた一本の絃/弁天M「鳴らないまま、張りつめてる」

## P3
- 1/戸口から猫又/猫又「姐さん、まだ起きてたのかい」
- 2/会話。帳簿を掲げる弁天/弁天「祭が近い。書き物が山なのさ」
- 3/猫又にやり/猫又「姐さんの三味線、久しく聴いてないよ」
- 4/弁天そっけなく/弁天「蔵の錠前、明日検めとくれ」

## P4
- 1/回想・セピア。幼い弁天の手を引く師匠の後ろ姿/師匠「音は里のために鳴らすもんだよ、弁天」/演出:祭提灯ぼんやり
- 2/現在。目を伏せる弁天/弁天M「だからあたしは、舞台を降りた」

## P5
- 1/障子を開ける弁天。夜気/―/効果音:カラ
- 2/ページ下2/3を使う大ゴマ(見開きにはしない)。夜空を流れる虹色の仮名「い」「ろ」「は」/―/効果音:……(無音演出)、文字は七色グラデ

## P6
- 1/見上げる弁天の瞳に文字が映る/弁天「……忍びいろは」
- 2/文字の流れが節に見えるイメージ。五線のように/弁天M「文字の運びが、節に聴こえる」
- 3/指が勝手に勘所を押さえている手元アップ/効果音:ピク

## P7
- 1/縁側で三味線を膝に。撥を構える/―/演出:月光
- 2/構えたまま止まる手/弁天M「夜更けだ。……里のために、か」
- 3/撥を下ろしかける/―/効果音:スッ

## P8
- 1/大ゴマ。虹色の一文字「ね」がひらりと舞い降りる/―/効果音:ひら…
- 2/三味線の胴に着地、ほどけて消える/―/効果音:ふわ…
- 3/胴に手を当てる弁天。頬にわずかな朱/弁天「……宛先を、間違えたのかい」
- 4/引き。弁天の胸のうちの絃が震えるイメージ/弁天M「微かに、鳴った」/演出:次話へ
