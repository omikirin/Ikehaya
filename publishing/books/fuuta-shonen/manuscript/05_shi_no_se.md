# 第5話 師の背、百の嵐

その夜、里は二つの敵に襲われた。

湊の側から骨喰一味。山の側から、悪霊・百嵐。

半鐘が乱打され、寺の境内に女子供が集められていく。三味線を背負った弁天様が山門の前に立ち、常と変わらぬ涼やかな声で下知を飛ばす。「女子供は寺へ! 男衆は湊へ! 山は——」山は、手が足りない。誰もが分かっていた。

「山は儂が塞ぐ」疾風斎は大小を差し、当たり前のように言った。「小僧は寺の護りにつけ」

「嫌だ。おれも行く」

「足手まといじゃ」

「師匠、言ったろ。おれの耳は夜目より利くって。あんたの左は、見えないんだろ」

疾風斎は一瞬黙り、それから初めて、少年に向かって深く笑った。

「……口だけは一人前になりおったわ。ついて来い。ただし儂の風下から出るな」

夜の山道を、二人は並んで駆けた。修行の日々、あれほど追い追われた師弟が、初めて同じ方向へ走っている。それだけのことが、風太には不思議と心強かった。頭上では雲が千切れ飛び、月が出たり隠れたりした。谷の奥から響く百嵐の唸りは、一足ごとに近く、重くなる。

「二手に分かれての夜討ち——偶然にしては出来すぎておるわ」走りながら、疾風斎が吐き捨てた。「これは骨喰の絵図よ。悪霊で山の護りを引き剥がし、手薄になった湊の蔵を襲う。里ひとつを天秤にかけた、外道の算盤じゃ」

北の尾根への道で、二人は骨喰の別働隊と出くわした。山側から寺を突く腹づもりか。覆面が五つ、鎌のような双刀が月光を撥ねる。先頭の男の左足が、わずかに地を引きずった。

——あの夜の音と同じ。頭だ。骨喰本人。

「ほう、爺と小僧か」骨喰の声は、刃物で笑うような声だった。「百嵐が里を喰らい終わるまでの、退屈しのぎにはなるか」

「抜け忍風情が、大きな口を利くわ」疾風斎が静かに言った。「鎌鼬の骨喰——流派の宝刀に手をつけて破門された男よ。首筋のその傷、追手に付けられたか」

覆面の上の目が、す、と細くなった。

「……忍びの掟が、俺に何をくれた。汗の分け前は師が取り、罪の分け前だけが俺に来た。ならば俺は、掟ごと里を喰らう側に回るまでよ」

吐き捨てる声の底に、一瞬だけ、笑いではないものが混じった。それを聴き取れる耳を、風太は持ってしまっていた。

風太の心の臓が、一つ大きく跳ねた。あの夜、背中を向けた相手。膝が笑いそうになる。だが今夜は、あの夜と違うものが二つあった。目の前に師の背中があること。そして、逃げた夜に聴いた音のすべてが、今は武器だということ。

戦いは一瞬だった。少なくとも風太の目にはそう見えた。疾風斎の剣は、大きく動かない。半歩の見切りと、最小の刃筋。野盗が二人、声もなく崩れた。骨喰の双刀が老人の死角——左から襲う。

「師匠、左、下!」

風太の声に、老人の剣が吸いつくように応じた。鍔鳴り一つ、骨喰の片刀が夜空に舞い、抜け忍は舌打ちして飛びすさった。

「……化け物めが。退くぞ!」

賊が闇に散った、その時だった。

尾根の上の森が、めきめきと音を立てて割れた。

来たのは、風ではなかった。百の嵐と呼ばれる由縁を、風太は全身で知った。杉の巨木ほどもある胴が、百千の脚を波打たせてうねり、無数の脚が一斉に山肌を掻くたび、嵐そっくりの轟音が谷を満たす。眼は白く濁った提灯のようで、開いた大顎から、腐った土の匂いの息が吹き下ろした。

「小僧、下がれ!」

疾風斎が前に出た。老人の剣が閃き、百嵐の脚が数本飛ぶ。だが斬り口から黒い霧が噴き、脚は見る間に生え直した。悪霊に、ただの刃は通らない。

「埒があかんわ……!」

百嵐の尾が、鞭のように薙いだ。疾風斎はそれを断とうと踏み込み——断った。確かに断った。だが断たれた尾の先が、毒針と化して老人の脇腹を掠めていた。

「師匠っ!」

老人の体が、ぐらりと傾いだ。斬られた傷は浅い。だが掠り傷から入るものこそ悪霊の毒だと、里の古老たちは言っていた。生きた百足の毒なら熱を持つ。悪霊の毒は逆だ。触れたところから、火の気が抜けるように冷えていく。

疾風斎が膝をつく。それでも老人は剣を杖に立ち上がり、少年を背に庇った。その背中は、風太が今まで見たどんなものより大きく、そして、初めて小さくも見えた。

「小僧……よう聴け。あれの脚は百あるが、息の口は一つ。動くたび、どこかで風が——」

「吸われてる」風太は言った。聞こえていたのだ、さっきから。嵐のような轟音の中心に、一箇所だけ、風が吸い込まれて消える静かな穴が。「頭の下。顎の付け根。あそこだけ、風が死んでる」

「……それが分かるなら」疾風斎は血の滲む脇腹を押さえ、笑った。「もう教えることは何もないわ」

老人の膝が、崩れた。風太は師の体を抱きとめた。まだ息はある。だが毒は熱のように広がっていく。百嵐が、ゆっくりと鎌首をもたげ、白濁した百の眼が少年一人に向いた。

「風太……」薄れる意識の中で、疾風斎が掠れ声を絞った。「風は——止まるな」

少年は師を岩陰に横たえ、立ち上がった。

正宗の鯉口を、切った。
