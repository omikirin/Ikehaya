# プロット — 地の底の百鬼、百足の忍ゴコウ奇譚

## ログライン
封印された根の国で百鬼の秩序を守る百足の忍ゴコウが、名を喰う怪異「虚蟲」から地の底の夜行を守り抜く妖怪奇譚。

## 三幕構成
- 第一幕(1〜2話): 封印下の根の国。帳持ちゴコウが守る百鬼夜行の秩序に異変。名を喰われた鬼が現れ、正体不明の「虚蟲」を追い始める。
- 第二幕(3〜4話): 封印の傷跡に辿り着き、虚蟲が封印の澱から生まれたと知る。初戦で敗れ、ゴコウ自身の名も喰われ始める。
- 第三幕(5〜6話): 名を失いかけたゴコウが「秩序は鎖ではなく百の足で支えるもの」と悟り、ささがねの糸を借りて封印の傷跡で虚蟲を討つ。里への敵意は消えぬまま、地の底の夜は続く。

## 全6話
1. 帳の底の百鬼夜行 — 根の国の夜行と帳持ちの役目を描く。夜行の列からひとり、名を呼ばれても答えぬ鬼が出る。/ 引き: その鬼の名が、帳面から墨ごと消えていた。
2. 名を喰うもの — 消えた名を追い、ささがねの糸を借りて痕跡を辿る。名を喰われた鬼は形も崩れ始める。/ 引き: 痕跡は、忌み地とされる封印の傷跡へ続いていた。
3. 封印の傷跡 — 岩爺・アトザらに封じられた日の記憶と、里への恨み。傷跡の澱から虚蟲が生まれたと知る。/ 引き: 夜行の半列が、音もなく喰われた。
4. 百足、裂かれる — 虚蟲との初戦。百歩百足も百節も通じず敗走。術の代償で節の感覚を失う。/ 引き: 帳面のゴコウ自身の名が、端から薄れ始めた。
5. 名も無き底で — 名を失いかけ、己が秩序を守る理由を見失う。ささがねが糸で「ゴコウ」の名を縫い留める。/ 引き: 虚蟲が帳面そのものを喰いに、宿へ迫る。
6. 百の足で立つ — 封印の傷跡での決戦。百鬼の名を呼びながら百歩百足を極め、虚蟲を帳の内に縫い封じる。/ 引き(結び): 里への恨みは捨てぬ。だが地の底には地の底の夜がある——夜行は今夜も列を成す。

## 主役の内的変化
「秩序は封印に押し付けられた鎖」と倦んでいたゴコウが、名を失う恐怖を経て「秩序とは百鬼一体一体の名を憶えて支える、己の百の足そのもの」と受け入れる。里への敵対心は保ったまま、帳持ちである己を選び直す。
