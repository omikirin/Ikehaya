# ネーム 第3話 風の峡谷(全10ページ)

## P1
- 1/大ゴマ。朝日に白く燃える大断崖の全景(超ロング)/モノローグ「高さ百丈。鳥でもなければ越えられぬ壁」
- 2/岩壁に手を当てるハヤテ/ハヤテ(……震えている。岩の奥を、風が通っている)
- 3/ナルカミを放つ/ハヤテ「ナルカミ、頼む」

## P2
- 1/座して印を結ぶハヤテ/SE: スゥ…
- 2/大ゴマ。上空からの断崖——幾重もの襞と、その間を蛇行する亀裂/モノローグ「壁は一枚ではない。襞の隙間に、隠された峡谷」

## P3
- 1/亀裂の入り口に渦巻く白い霧(鷹視点)/SE: ゴォォ
- 2/絵図の渦印と実景を重ねる演出コマ/ハヤテ(渦印は宝の在処じゃない——「風の渦が立つ場所が入り口」!)
- 3/(小)上空視点。崖の手前で銀の線が二股に分かれているのがはっきり見える(第4話への伏線。さりげなく、だが読者に見えるサイズで)/ハヤテ(……二股? 写し違いか)
- 4/拳を握る/ハヤテ「解けたぞ……!」

## P4
- 1/よろめき岩壁に手をつく/SE: グラ…/ハヤテ(今朝で三度目……効いてくるな)
- 2/それでも笑って口笛/SE: ピュウ
- 3/襞の裏、金の紗のような霧と黒い亀裂/ハヤテ「行くぞ、ナルカミ。落ちるなよ」/ナルカミ、素知らぬ顔

## P5
- 1/狭い亀裂を横歩き/SE: ズ…ズ…
- 2/大ゴマ。頭上に青空の帯を頂く大峡谷(見上げ構図)/SE: ゴオオオ
- 3/突風に身を伏せる。頭上でナルカミが翼を傾ける/モノローグ「鷹が翼を畳めば伏せ、開けば進む。言葉より速い符牒」

## P6
- 1/三叉路。同じような三つの谷/ハヤテ「……分かれ道か」
- 2/地上から絵図を見るが白紙/SE: シーン
- 3/空を仰ぐ/ハヤテ「ナルカミ。空はどうだ」

## P7
- 1/鷹の目発動、こめかみに走る痛みの演出(ヒビ割れ表現)/SE: ズキィ!
- 2/上空視点。中央と左の谷底には草、右だけ岩肌剥き出し/ハヤテ(風が通り続けている谷は——)
- 3/確信の目/ハヤテ「右だ」

## P8
