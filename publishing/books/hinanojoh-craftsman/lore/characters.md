# 公式設定要約(出典: NINJAMCP / だんく「【保存版】CryptoNinja 世界観とキャラクター設定まとめ」)

## 雛之丞(Hinanojoh / #011)— 主役
- クラン: 雑賀 / 忍術: 火遁(Katon) / 武器: 焙烙玉(Horoku bomb)
- 誕生日: 2月8日(「にわとりの日」にちなむ)
- プロフィール: 勇敢な爆弾使いで、自爆寸前まで攻め続ける。ただし油断するとヒヨコの姿に戻ってしまう。
- 公式画像: https://cn-lore-mcp.nubonba.workers.dev/images/011.jpg

## 弁天(Benten / #023)— 関係キャラ
- クラン: 雑賀 / 忍術: 祝詞(Mantra) / 武器: 三味線 / 誕生日: 3月4日
- 孫市(#034)から里の管理を任されている。

## 孫市(Magoichi / #034)— 関係キャラ(言及のみ)
- 雑賀クランの首領。銃/一発必中。めったに里へ戻らず、里の運営は弁天に一任。海に出て海賊さながらの活動。

## 風太(Fuuta / #018)— 関係キャラ
- 雑賀 / 風遁 / 正宗。酒好きで陽気。争いを好まず逃げることが多いが、いざという時は実力を発揮。誕生日は「日本酒の日」。

## 世界観(シーズン2=現代を舞台とする)
- 平和な時代。伊賀・甲賀・風魔・雑賀の4クランに大きな対立はなく、忍者は鬼や悪霊の退治、里のトラブル解決を担う。
- 根の国はシーズン1で岩爺・アトザたちにより封印済み。シーズン3で再び脅威となる(本作では封印は保たれたまま)。
