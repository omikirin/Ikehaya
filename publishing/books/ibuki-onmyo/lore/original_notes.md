# 本作独自解釈の列挙(公式設定ではない)

1. 「命の帳簿(いのちのちょうぼ)」: 泰山府君の司る寿命の台帳。イブキは術者として、人の頭上に残りの命が「墨の濃淡」として視える、という本作独自の設定。
2. 各話の怪異(灯取蛾・逆さ暦・空谺・写し文・身代わり雛)はすべて本作オリジナルの怪異。公式に存在しない。
3. 敵役「無戸(むこ)」: 帳簿の外に落ちた元・泰山府君祭の術者。本作オリジナルの敵であり、公式キャラを悪役にしない方針に基づく創作。
4. ヤーマの言動・口調(古雅な物言い、餅を好む等)は本作独自の肉付け。「力量に応じて姿が変わる」性質のみ公式準拠。最終話で一瞬だけ真の姿の片鱗が見える描写は独自演出で、恒久的な変化はさせない。
5. イブキが風魔の里はずれの祠「府君堂」を預かる、師が既に亡いという経歴は独自設定。
6. 泰山府君祭の作法(北斗を拝す、呪符十二枚、代償として術者自身の寿命が墨と共に減る)は史実の陰陽道を参考にした本作独自の術式描写。効果は公式記述(術名のみ)を超えて盛らず、「寿命を書き換える力は未熟なイブキには行使できない」制約を課す。
