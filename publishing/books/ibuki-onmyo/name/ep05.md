# ネーム 第五話 身代わり雛(全10ページ)

## P1
- 1/府君堂。行灯の下、師の帳面を繰り続けるイブキ。荒れた指/効果音: ぱら…ぱら…
- 2/帳面の一行のアップ「命ノ帳ハ、府君ノ御手ニノミ在リ。地上ノ術者ハ、読ミ、送ルノミ」
- 3/乾いた笑いのイブキ/イブキ「読み、送るのみ、か。ならばこの眼は何のためにある」

## P2
- 1/ヤーマ、帳面に前脚を乗せる/ヤーマ「三日、飯を食うておらぬぞ」
- 2/夢: 帳面を繰る師の後ろ姿/師「視える者の修行は、視えたものと共に座る修行だ」
- 3/目覚め。闇にぼんやり白い木箱/効果音: しん…

## P3
- 1/戸口の木箱。雪に足あとが無い/効果音: ぞく
- 2/蓋を開く。ひび割れた白い顔の男雛と女雛/効果音: カタ…
- 3/添え文「身代わり雛。移したき命の名を女雛の背に——」朱印
- 4/毛を逆立てるヤーマ/ヤーマ「捨てよ。それは餌だ」イブキ「……分かっている」

## P4
- 1/日に日に細る小夜。縁側で雪兎をこしらえる/小夜「春になったら、杉の一番上の雪が落ちるところを見るの」
- 2/イブキ、目を伏せて/イブキ「……ああ。見るがよい」
- 3/帰り道、足を止めるイブキ。懐から筆/モノローグ「指が、勝手に動いていた」

## P5(見開き前半・山場)
- 1/大ゴマ。囲炉裏の火に照らされ、女雛の背に「小夜」と書くイブキ/効果音: すぅ…
- 2/男雛を握り、おのれの名を書こうとする筆先のアップ

## P6(見開き後半)
- 1/大ゴマ。「いぶき」——囲炉裏の向こう、初めて見る審きの色の目をしたヤーマ/ヤーマ「否、だ」
- 2/イブキ「おれの命は、おれのものだ。半分やって小夜が春を見られるなら」
- 3/ヤーマの声が梁を震わせる/ヤーマ「よく視よ、術者。おまえの眼は、何のためにある」/効果音: ビリ…

## P7
- 1/大ゴマ。イブキの視点: 雛の腹の奥の墨の管。名は女雛へ流れず、戸倉の闇へ通じている/効果音: ゾッ
- 2/筆が手から落ちる/効果音: からん

## P8
- 1/雛を火にくべるイブキの震える手/効果音: パチ…
- 2/火の中で開く白い顔のひび。じっとイブキを見る雛/効果音: ぴし…
- 3/板の間に手をつくイブキ/モノローグ「救いたい心の形をした穴から——あの男も落ちたのだ」

## P9
- 1/イブキ「ヤーマ。おまえは、なぜ止められる」
- 2/ヤーマ、外の雪明かりを見る/ヤーマ「わしは帳簿の主の側の者よ。おまえが穴に落ちぬよう、縁で見ておるのが役目だ」

## P10(引き)
- 1/ヤーマの細めた目のアップ/ヤーマ「三日の後は大晦日。おまえの生まれた日。大祓の日」
- 2/大ゴマ。雪の府君堂遠景、北斗七星/ヤーマ「本祭の夜、帳簿は地上に最も近づく。——無戸は必ず来るぞ」(次話へ)
