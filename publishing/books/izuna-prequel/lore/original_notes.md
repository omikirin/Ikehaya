# 本作独自解釈メモ(公式未確定部分の創作)

- **既刊 uka-dark-fantasy とは独立した作品として書く。** 同シリーズの設定・出来事は一切引き継がず、本作単体で完結する前日譚として読めるようにする。
- 時代設定: シーズン2(平和な時代)の「前日譚」。宇迦の誕生からイズナの視点で描く年代記。世界の大事件は起こさず、姉妹の日々の選択で読ませる。
- 両親の設定(早くに亡くなり、姉が妹を育てる)は本作オリジナル。公式に両親の記述はない。
- 飯綱の法の描写(管狐に似た小さな白い霊獣「管(くだ)」を身に宿し、気配を読み、風を運び、病鬼を祓う——武器を持たない守りの術)は本作独自の解釈。効果は公式記述の範囲を超えて盛らない。代償として術者の体温と眠りを削る設定も独自。
- 宇迦の「九尾の焔」の萌芽(幼少期に狐火を暴発させる)や護符の由来(姉が書き方を教えた)は本作オリジナル。
- 於兎は妹の好敵手として好意的に登場。悪役にしない。敵は「山に湧く病鬼(名もなき悪霊)」という本作オリジナルの存在のみ。
- 甲賀の里の描写(段々畑、稲荷の祠、冬の水汲み等)は雰囲気づけの独自ディテール。
