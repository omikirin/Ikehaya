# ネーム 第3話 火は叱れない(全10ページ)

## P1
- 1/成長した宇迦(6歳)が畑で転ぶ、水をこぼす、笑う、の三連小コマ/宇迦「ねえね、あたし働き者でしょ」
- 2/嬉しさで髪の先に灯る小さな火/効果音: ぽっ
- 3/家の四隅の水瓶を描く俯瞰/モノローグ「感情が高ぶると、火は出た」

## P2
- 1/夕暮れの山裾。鬼ごっこ。届かぬ間合いでからかわれる宇迦/子ら「こっちこっちー」
- 2/宇迦の顔が歪む/宇迦「もう…」
- 3/溜めの小コマ・握られた拳/効果音: ぷつ…

## P3(山場・右)
- 1/大ゴマ・「もうやだ!」体のまわり全部から噴く青白い火。夕風に横走りする炎/効果音: ゴォッ!

## P4(山場・左)
- 1/焼けた粟畑ひと畝。棒立ちの宇迦が自分の両手を見下ろす/効果音: ちり、ちり…
- 2/遠巻きの大人たちの目配せ(顔は描かず目だけ)/モノローグ「その目配せのほうが、どんな叱声より鋭い」

## P5
- 1/畑の持ち主に深く頭を下げるイズナ/イズナ「繕い物三月ぶんで、償わせてください」
- 2/手を引かれ俯いて歩く宇迦。夕餉の匂いの家々/効果音: とぼ…とぼ…
- 3/氷のように冷たい宇迦の手のアップ/モノローグ「あれだけの火を噴いた手が、だ」

## P6
- 1/家。先に口を開く宇迦/宇迦「ねえね、あたしを叱って」
- 2/正面のイズナ、静かな目/イズナ「火は叱れない」
- 3/イズナ「火を叱れば、おまえは火を憎むようになる。火には、道を教える」

## P7
- 1/行李の底から油紙の包みを出す/モノローグ「母の残した、護符の書き方だった」
- 2/細かい字の控えのアップ/モノローグ「母は、いつか娘の誰かがこれを要ることを知っていた」
- 3/イズナ「火が言うことを聞かない日は、この札に火を預けるんだ」

## P8

- 2/字の躍る二枚目/効果音: のたのた
- 3/息を詰めて書く三枚目。舌をしまった真剣な顔/効果音: すっ…

## P9
- 1/大ゴマ・不格好な札に火が吸われ、紙の上で行儀よく小さくなって消える/効果音: ふ…/宇迦「……きえた」
- 2/イズナ「預かってもらったんだ。偉かったね」
- 3/ぱっと明るくなる宇迦、髪に火が灯りかけ慌てて札を掴む/効果音: ぽっ→バッ
