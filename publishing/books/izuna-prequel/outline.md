# プロット — 灯を持たぬ手 イズナ前日譚

## ログライン
武器を持たない術者イズナが、妹・宇迦の誕生から狐使いとして立つ日までを見守り、「守るとは手を放すことだ」と知るまでの年代記。

## 三幕構成
- 一幕(第1〜2話): 宇迦の誕生と両親の死。イズナは飯綱の法だけを頼りに、幼い妹と里で生きる覚悟を決める。
- 二幕(第3〜4話): 宇迦の狐火の暴発、於兎との出会い。イズナは「抱え込む守り」の限界に直面する。
- 三幕(第5〜6話): 山の病鬼の流行。イズナは自分の術の本当の使い途を見出し、宇迦を狐使いとして送り出す。

## 全6話
1. **初午の雪** — 初午の日、宇迦が生まれる。幼いイズナは管(くだ)に妹の産声を聞かせる。/引き: 母の床に、管が不吉な冷えを嗅ぐ。
2. **手のなかの火種** — 両親が流行り病で逝く。イズナは妹を抱いて祠に誓う。/引き: 眠る宇迦の指先に、小さな狐火がともる。
3. **火は叱れない** — 宇迦の狐火が暴発し畑を焦がす。里の目が冷たくなり、イズナは護符の書き方を妹に教える。/引き: 「姉さまはどうして武器を持たないの」
4. **兎と狐** — 於兎が現れ、宇迦と初めて競い合う。負けて泣く宇迦に、イズナは初めて手を出さず見守る。/引き: 山から下りた風が、病鬼の臭いを運んでくる。
5. **病鬼の冬** — 里に病鬼が湧く。イズナは眠りと体温を削って結界を張り続け、倒れる。/引き: 意識の際で、宇迦が九尾の焔を呼ぶ声を聞く。
6. **灯を持たぬ手** — 宇迦の焔が病鬼を祓い、イズナの管がその火を里の外へ導く。姉妹それぞれの「守り方」が重なる。宇迦は狐使いとして立ち、イズナは笑って手を放す。

## 主役の内的変化
「妹を危険から遠ざけること」を守りと信じていたイズナが、日々の小さな選択を経て、「妹が自分の力で立つ場所をつくること」こそ武器を持たない自分の守り方だと受け入れる。
