## 蛇ノ目(Janome / #022)— 主役
- クラン: 風魔 / 忍術: 口寄せ(Kuchiyose) / 武器: 毒手裏剣 / 誕生日: 7月16日(世界ヘビの日)
- 口寄せの術で白蛇の「オロチ」を呼び出す。どこか抜けた一面があり、しばしばオロチに助けられている。
- 公式画像: https://cn-lore-mcp.nubonba.workers.dev/images/022.jpg

## アトザ(Atoza / #013)— 風魔首領
- 忍術: 逢魔刻 / 武器: 棍棒。首領格でありながら情に厚い。アウンの兄。呂屯・断を部下に持つ。シーズン1で岩爺たちと根の国を封印。

## イブキ(Ibuki / #035)— 「信じてくれる一人」
- 風魔 / 忍術: 泰山府君祭 / 武器: 呪符。パートナー「ヤーマ」を伴う。未熟ゆえヤーマは愛らしい姿。誕生日12月31日(大祓の日)。

## 呂屯(Rotten / #007)— 参考(毒の同業者)
- 風魔幹部、アトザ配下。忍術: 毒霧 / 武器: 毒矢。

## 世界観
- シーズン2(平和な現代)。4クランは共存し、鬼や悪霊の退治・里のトラブル解決を担う。根の国はシーズン1で封印済み。
