# ネーム 第3話 信じる者(全10ページ)

## P1
- 1/夕暮れ、戸を叩く音/効果音「トントン」
- 2/戸を開けると小さな影。イブキ登場、肩に毛玉のヤーマ
- 3/蛇ノ目「ここに来たら、まずいぞ」/イブキ、竹皮の包みを突き出す「差し入れです」
## P2
- 1/イブキの顔アップ、まっすぐな目/「蛇ノ目さんは、オロチに指を噛まれて騒いで、毒の話になると急に真面目になる人です」
- 2/言い切るイブキ/「管理帳を三度読み返す人が、寄合の茶に毒なんて雑なことをするわけがありません」
- 3/言葉を失う蛇ノ目。目の奥が熱い/モノローグ「三日ぶりに聞いた、疑いの混じらない声だった」
- 4/顔をそむけて/蛇ノ目「……入れ。飯は二人で食ったほうがうまい」
## P3
- 1/囲炉裏。オロチとヤーマの睨み合い→等距離に落ち着くコミカル3連
- 2/笑う二人/モノローグ「三日ぶりに、家の中に人の声があった」
## P4
- 1/消えた手裏剣の件を話す蛇ノ目(深刻)
- 2/イブキ「なら、調べましょう」/「割れた茶碗が、寄合所の裏に」
- 3/蛇ノ目「お前まで白い目で見られるぞ」
## P5
- 1/ヤーマを撫でるイブキ、大人びた表情/「その符を預かる者が、生きてる人の裁きから逃げてどうするんですか」
- 2/参ったなという顔の蛇ノ目/モノローグ「後輩のほうがよほど肚が据わっている」
- 3/ふと訊く蛇ノ目「その符は、死んだ者の声も拾うのか」/イブキ「死者は還りません。ただ、強い未練だけは、符に微かな声を残すことがあるそうです」
## P6
- 1/夜、寄合所裏に忍ぶ二人(蟄居破りの緊張)
- 2/筵の上の割れた茶碗
- 3/印を結ぶ蛇ノ目/「口寄せ」
## P7(山場)
- 1/術の発動大ゴマ。掌の熱、白い吐息、痺れる指先/モノローグ「呼び出す命の分だけ、術者の熱を渡す」
- 2/オロチが腕を伝い茶碗へ滑り降りる
## P8
- 1/オロチの舌が茶の跡を探るアップ連続/効果音「ちろ…ちろ…」
- 2/待つ蛇ノ目、肘まで上がる痺れ/モノローグ「オロチの舌は嘘を吐かない」
- 3/固唾を呑むイブキとヤーマ
## P9
- 1/オロチ、首をゆっくり左右に振る大ゴマ
- 2/息を吐く蛇ノ目/「違う。おれの毒じゃない。オロチの毒でもない」
## P10(引き)
- 1/月にかざした茶碗のかけら、釉薬に光る粉
- 2/蛇ノ目の目に点る火/「蛇の毒じゃない。蛇のふりをした毒だ」/次話へ
