# ネーム 第4話 薬師の影(全10ページ)

## P1
- 1/囲炉裏端、推理する蛇ノ目/「症状を蛇毒に似せるには、薬師の腕がいる」
- 2/指を折る手元。甚平、そして…
- 3/イブキ「……卯堂さん」
## P2
- 1/蛇ノ目「待て。決めつけはいかん」/「おれは決めつけられる側の痛みを、今まさに味わってる」
- 2/火を突く蛇ノ目/「匂いと、毒草と、手立てと、三つ揃えてからだ」
## P3
- 1/翌夜。卯堂の家裏の薬草畑俯瞰。垣根の外の二人
- 2/オロチが畝の間を流れる白い線
- 3/印を保つ蛇ノ目、下がる体温/イブキが羽織を掛ける
## P4
- 1/オロチの探索モンタージュ(畝×舌のアップ)
- 2/動きを止めるオロチ。土の新しい一角
- 3/戻ったオロチが腕を三度締める/モノローグ「あった」
## P5
- 1/蛇ノ目「これで首領に――」
- 2/夜空に響く呼び鈴/効果音「リン…リン…」
- 3/二人、顔を見合わせる
## P6(見開き山場・P6-7)
- 1/【見開き】灯り煌々の寄合所。壇上の卯堂が布を開く。載っているのは毒手裏剣一本/卯堂「甚平どのの軒下に、これが」
## P7
- 1/どよめく人垣/効果音「ザワッ」
- 2/垣根の陰、目の前が暗くなる蛇ノ目。袖を掴むイブキの手
- 3/拳を握る蛇ノ目/モノローグ「半分の真実を混ぜた嘘は、鉄より硬い」
## P8
- 1/卯堂の青白い顔アップ/蛇ノ目(小声)「あんた、先回りしたな」
- 2/壇上で目を閉じるアトザ
- 3/アトザ「明後日の朝、寄合を開く。それまで誰も手出しはならん」
## P9
- 1/帰り道。イブキ「なぜ甚平さんを。恩人なのに」
- 2/蛇ノ目「これで終わる男の目じゃなかった」/モノローグ「卯堂の目は、まだ満ちていなかった」
## P10(引き)
- 1/人垣の中の与市(行商人)に粘りつく卯堂の視線。それを見ているオロチの目のアップ/モノローグ「次の狙いは――」/次話へ
