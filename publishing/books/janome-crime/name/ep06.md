# ネーム 第6話 白蛇の証(全12ページ)

## P1
- 1/晴れた朝の寄合所外観
- 2/板間に里じゅうの人々。上座アトザ、壇下に蛇ノ目・卯堂・与市。末席のイブキとヤーマ
- 3/晒しを巻いた蛇ノ目の右手アップ/モノローグ「末席に一人、まっすぐこちらを見ている後輩がいる。それで足りた」
## P2
- 1/アトザ「順に話せ」
- 2/語る蛇ノ目のモンタージュ前半(消えた手裏剣・割れた茶碗)
- 3/モンタージュ後半(毒草の畑・燃える帳面)
- 4/静かに首を振る卯堂/「わたしは薬湯を勧めただけです」
- 5/傾く場の空気/効果音「ザワ…」
## P3
- 1/前へ出る蛇ノ目/「首領。二つ、検分を願いたい」
- 2/「一つ。おれの毒庫の仕掛け錠。壊さず開けるには蝋で型を取るしかない。卯堂の薬箱の封蝋と、錠前の溝を比べてくれ」/インサート小コマ・第4話P4の蝋の削り滓の匂い(第4話P4-4と同カット)
- 3/走る検分役
## P4
- 1/蛇ノ目「二つ目は――口寄せの術だ。この場で使う許しを」
- 2/怯えの走る人垣/効果音「ザワッ」
- 3/長く見るアトザの目/モノローグ「測っているのは術の危険ではなく、蛇ノ目という男そのもの」
## P5
- 1/アトザ「使え。ただし、皆が見ている前でだ」
- 2/蛇ノ目「それでいい。むしろ、それがいい」
## P6-P7(見開き山場・偶数-奇数の対向面)
- 1/【見開き大ゴマ】板間中央、印を結ぶ蛇ノ目。白い吐息、白む視界、現れる白蛇オロチ。皆が見守る中を音もなく渡る白い軌跡/効果音「シュル……」
- 2/(P7左下・端コマ)薬箱の前で止まるオロチ。蓋の隙間に舌
- 3/(P7左下・端コマ)三度、首を振る/蛇ノ目「茶碗と同じ匂いだ。蛇毒に似せた毒が、まだ箱の底にある」
## P8
- 1/「蛇の申すことなど」と言いかける男
- 2/戻る検分役、掲げる蝋の細片/「錠の溝に、朱の混ざった封蝋が」
- 3/肩から力の抜ける卯堂
## P9
- 1/焦げた切れ端を差し出す蛇ノ目/「与市さんに検めてもらえばいい」
- 2/控えの帳面と切れ端を一行ずつ突き合わせる与市の指/与市「……数が、合いません。卸してもおらん薬が載っております」
- 3/立ち上がるイブキ。震える手の呪符/祝詞
- 4/風もないのに震える呪符大ゴマ/効果音「カタカタ…」
## P10(山場)
- 1/板間に落ちる掠れた老人の声/『……すまなんだ……』
- 2/両手で顔を覆う卯堂
- 3/長い沈黙ののち顔を上げる。初めて生きた目/「……わたしが、やりました」
## P11
- 1/回想小コマ・蝋を錠に流し型を取る卯堂の手元/卯堂(声)「蝋で、錠の型を取り」
- 2/回想小コマ・夜、窓の隙間から毒庫の並びを数える目/「夜ごと、並びを数えており申した」
- 3/回想小コマ・甚平の軒下に手裏剣を刺す手/「手裏剣は、甚平の軒下に」
- 4/畳に額をつける卯堂。何も言わない蛇ノ目
- 5/蛇ノ目→アトザ/「山向こうの村々のことも、調べてやってくれ」
## P12(結・引きなし/余韻)
- 1/寄合後。アトザ「疑うて、すまなんだな」/蛇ノ目「首領は疑ったんじゃない。調べたんだ」
- 2/頭を下げていく里の人々。干し柿をオロチに差し入れる蛇ノ目/「また誰かに疑われるかもしれん」
- 3/イブキ「そのときは、また握り飯を持っていきます」
- 4/秋の陽に光る白蛇の鱗、笑う二人の引き絵/モノローグ「毒を扱うこの手は、人を守るための手だ」/完
