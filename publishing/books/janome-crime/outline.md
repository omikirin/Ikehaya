# プロット — 白蛇は嘘を吐かない

## ログライン
毒殺事件の濡れ衣を着せられた毒使いの忍・蛇ノ目が、相棒の白蛇オロチと、ただ一人信じてくれた後輩イブキとともに真犯人を追い詰める無実証明サスペンス。

## 三幕構成
- 第一幕(1〜2話): 里の寄合で薬売り甚平が毒殺。毒の症状が蛇毒に酷似し、毒手裏剣を扱う蛇ノ目に容疑がかかる。蟄居を命じられ、里の視線が一変する。
- 第二幕(3〜4話): イブキだけが信じてくれる。オロチの嗅覚で毒が「蛇毒に似せた植物毒」と判明するが、蛇ノ目の毒庫から手裏剣が一本消えており、証拠はむしろ深まる。薬師・卯堂の影。
- 第三幕(5〜6話): 卯堂の動機(甚平に故郷を潰された過去)と偽装の手口を暴く。第二の毒殺を阻止し、寄合の場で口寄せの術とイブキの呪符が真実を照らす。疑いは晴れ、蛇ノ目は「疑われても、一人が信じてくれれば立てる」と知る。

## 全6話
1. 第1話 寄合の夜 — 毒殺事件発生。症状は蛇毒。視線が蛇ノ目に集まる。引き: 「その毒、おぬしのものではないのか」
2. 第2話 蟄居 — 蟄居処分。里の孤独。毒庫を検めると手裏剣が一本消えている。引き: 消えた一本は、誰の手に。
3. 第3話 信じる者 — イブキが訪ね、二人だけの調べが始まる。オロチが毒の匂いの違和を嗅ぎ取る。引き: 「これは蛇の毒じゃない。蛇のふりをした毒だ」
4. 第4話 薬師の影 — 毒草の出所を辿り薬師・卯堂へ。だが卯堂は先回りして蛇ノ目を告発、追い詰められる。引き: 次の狙いは寄合のもう一人。
5. 第5話 第二の毒 — 次の標的を守るため夜の蔵へ。卯堂の過去と動機が明かされ、対決。引き: 捕えたはずの証拠が、灰になる。
6. 第6話 白蛇の証 — 寄合での裁き。オロチの嗅覚とイブキの呪符、甚平の残した帳面が真実を示す。卯堂は罪を認め、蛇ノ目は里に戻る。

## 主役の内的変化
「抜けていて、毒使いゆえに一歩引かれてきた」蛇ノ目が、孤立の中で自分の毒=自分の在り方を恥じるところから始まり、オロチとイブキの信頼を支えに「毒を扱う手は、人を守るための手だ」と自分を引き受け直すまで。
