# 公式設定要約(出典: NINJAMCP / note「【保存版】CryptoNinja 世界観とキャラクター設定まとめ」だんく氏)

## 金鬼(Kana-Oni / #005)— 主役
- クラン: 伊賀(ただしプロフィールでは「特定のクランには属さない自由な立場」)
- 忍術: 金遁(Kinton)
- 武器: 牛刀(Gyuto)
- 誕生日: 11月8日(刃物の日にちなむ)
- プロフィール: 山奥に暮らす伝説級の鍛冶職人。
- 公式画像: https://cn-lore-mcp.nubonba.workers.dev/images/005.jpg

## 結(Yui / #017)— ゲスト登場
- クラン: 伊賀 / 忍術: 桜吹雪 / 武器: 巻物 / 誕生日: 10月15日
- 前線に出ず後方支援特化。岩爺(#016)の孫、令(#019)の娘。

## 岩爺(Ganzi / #016)— ゲスト登場
- クラン: 甲賀 / 忍術: 幻術・漆黒 / 武器: 数珠 / 誕生日: 9月15日
- 娘は令、孫は咲耶・結。シーズン1でアトザたちと共に根の国を封印。

## 世界観(シーズン2=現代を舞台とする)
- 伊賀・甲賀・風魔・雑賀の4クランが大きな対立なく共存する平和な時代。
- 忍者たちは鬼や悪霊の退治、里のトラブル解決を担う。
- 根の国はシーズン1で封印済み(本作では登場させない)。
