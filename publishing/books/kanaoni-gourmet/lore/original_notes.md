# 本作独自解釈(公式設定にない創作部分の列挙)

1. **金遁=調達術の解釈**: 公式では金遁の効果詳細は未設定。本作では「金属の気配を読む術」を拡張し、良い鉄・良い鍋・良い食材(土中の根菜や沢の砂鉄気を含む水脈まで)の在り処を聞き当てる「調達術」として解釈する。戦闘強化には使わない。
2. **牛刀=包丁**: 公式武器「牛刀」を、鍛冶職人が自ら打った万能包丁として運用。人を斬る描写はしない。
3. **里の台所番**: 金鬼が山奥の鍛冶場のかたわら、里外れに竈場(くりやば)「金鬼の台所」を構え、任務帰りの忍びに飯を振る舞う——という設定は本作オリジナル。
4. **一話一品の料理**: 各話の料理(粥・焼き味噌握り飯・猪鍋・秋刀魚・根菜汁・打ち立て蕎麦等)はすべて創作。
5. **ゲストの悩み事**: 結の稽古の行き詰まり、岩爺の旧い悔いなど、各話の「凝り」の中身は本作の創作(公式の関係性・立場とは矛盾させない)。
6. **敵役**: 悪役は登場させない。障害は天候・素材・人の心の凝りとする。行商人「銀次」など脇役は本作オリジナル。
7. **金鬼の口数の少なさ・過去の逸話**(若き日に打った刀への悔い)は創作。公式プロフィール「伝説級の鍛冶職人」「自由な立場」と矛盾しない範囲で描く。
