# ネーム 第3話 金翅鳥の末(全9ページ)

## P1
- 1/山中の庵。囲炉裏の火/前話引き回収:水に浸しても輝きを失わない金の羽根/モノローグ「焦げ跡の下の輝きは、消えなかった」
- 2/焦げた右翼を検分するカルラ/モノローグ「抜け替わるまで、ひと月」
- 3/痺れた右手の三本指を見る/モノローグ「代償は、いつも後から利いてくる」

## P2
- 1/回想・小コマ:箸を持てなくなった父の右手/モノローグ「雷は借り物だ。借りた分は体で払う」
- 2/回想:死ぬ間際まで西の空の匂いを嗅ぐ父の横顔
- 3/我に返るカルラ。薪の爆ぜる火の粉/SE:パチッ

## P3
- 1/庵の奥の漆の文箱。埃を払う手/モノローグ「翼が焼けた日に、開けよ」
- 2/文箱を開ける。中に絵詞一巻と金色の羽根一枚/SE:カタ…
- 3/掌の羽根と文箱の羽根を並べる。同じもの/カルラの見開いた目

## P4
- 1/絵詞を広げる。古い筆致(絵巻風の作画指定)/詞書「我らは迦楼羅天の加護を受けし鳥の末」
- 2/絵巻内イメージ:金の翅の巨鳥・迦楼羅。毒龍を喰らい、口に炎を含む/演出:金と朱の二色イメージ
- 3/詞書「空に湧く災いを、地に届く前に断つ。空の結界の番人として」

## P5
- 1/絵巻の後半。黒い巨鳥の絵/詞書「虚雷。雷を喰らいて肥ゆる空の妖」
- 2/カルラの背筋に走る冷たいもの/モノローグ「地の底の封じられし国の気、綻びより漏れ——」
- 3/イメージコマ:遠い昔、根の国を封印する先人たちの影(シルエットのみ)/モノローグ「喰った雷は餌ではない。里へ落とすための、蓄えだ」

## P6-7(見開き・山場)
- 1/見開き。絵巻最後の一葉を誌面いっぱいに。金の翅を広げ黒い巨鳥へ独り挑ぶ先代。雲の下の隅に空を見上げる里の人々の小さな列/詞書「先代、独りで昇り、独りで虚雷を討ち、還らず」
- 2/(P7右下)文箱の金の羽根のアップ/モノローグ「形見、だったのだ」

## P8
- 1/囲炉裏の火を見つめるカルラの長い沈黙。引きの構図(セリフなし)
- 2/インサート:絵詞の「還らず」の三文字/短句「独りの最期は——三文字」
- 3/己の焦げた黒羽根の芯に金色が覗くアップ/短句「迦楼羅の血は、焼けた時にだけ色を見せる」
- 4/カルラ自問/モノローグ「里に報せるか。……いや、それがいつも独りに戻る理屈だ」

## P9(引き)
- 1/夜半。戸を開けるカルラ。風が変わる/SE:ヒュウ…
- 2/移動を始める積乱雲の遠景。雲を押す巨影の気配
- 3/進路の先を辿るカルラの目→見開かれる/SE:ドクン
- 4/縦長コマ。北東の空、まばらな里の灯/煽り「虚雷が、里へ向かった」
