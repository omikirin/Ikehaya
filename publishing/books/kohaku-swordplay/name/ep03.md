# ネーム 第三話 双子の間合い(全9ページ)

## P1
- 1/寄合の広間。上座の重役たち、末席で頭を下げる狐白「調べは俺がやる。風魔の名にかけて」
- 2/交わされる疑いの視線(目だけのコマ)/タイトル「第三話 双子の間合い」

## P2
- 1/工房で帳面を繰る狐白。十年分の納め先
- 2/山向こうの荒れた鍛冶小屋(回想的挿画)/ナレ「鞘の主は五年前に死んだ元風魔の刀鍛冶。線はそこで切れた」

## P3
- 1/茶屋の前、桜のつぼみの枝の下に咲耶「甲賀から加勢に来ました。狐白さん、ですよね」
- 2/(大ゴマ)固まる狐白。モノローグ「双子の妹。——彼女は知らない。俺だけが知っている」
- 3/咲耶「他クランの目が入ったほうが疑いは晴れやすい。おじいさまもそう言っています」

## P4
- 1/昼の聞き込みモンタージュ。小鳥が屋根で噂を拾い、小狐が縁の下を嗅ぐ
- 2/咲耶「狐白さんの調べ、地味ですね」/狐白「地味なのがいちばん破れない」
- 3/咲耶「あ、それおじいさまも言います」/言葉に詰まる狐白(コメディ小コマ)

## P5
- 1/夜の張り込み、屋根の上。狐白の膝で丸くなる白い小狐
- 2/咲耶(笑いをこらえて)「懐かれてますね。狐面のせいかな」/狐白「……狐に狐が懐いてどうする」
- 3/咲耶「あ、今ちょっと笑いました?」/面のアップ(内心を見透かされる)

## P6
- 1/咲耶「前から不思議で。あなた、私と目を合わせないでしょう」
- 2/「嫌ってる人は、膝の上の狐をそんなに丁寧に撫でません」/止まる狐白の手
- 3/沈黙の夜空。それ以上聞かない咲耶の横顔

## P7
- 1/五日目の夜。小狐たちが空き寺に「空っぽの気配」を嗅ぎ当てる/SE:クンクン…ッ!
- 2/踏み込む二人。冷えた竈、壁の武具/SE:ガラッ

## P8(山場)
- 1/(大ゴマ)床板の上の書き付け。『次は風魔の変わり身。あの半拍、俺が貰い受ける』
- 2/読み上げる途中で声を止める咲耶。ゆっくり狐白を見る「これ……標的は、あなた」
- 3/狐白「らしいな」(平坦を装う面)

## P9(引き)
- 1/咲耶「囮になる気ですね。顔に書いてあります」/狐白「面を着けている」/咲耶「面の下に書いてあります」
- 2/帰り道、半歩前の咲耶「あなたが斬られたら、私、たぶんすごく困るので」
- 3/(ラスト)夜桜のつぼみ越しの二人の背中/モノローグ「この娘の前で、俺はいつまで偽りの顔でいられるのだろう」/次話へ
