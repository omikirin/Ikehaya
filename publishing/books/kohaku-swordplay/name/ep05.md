# ネーム 第五話 偽りが偽りを斬る(全10ページ)

## P1
- 1/夜の町を歩く「偽の狐白」の目撃図(町人の怯えの目)/ナレ「狐白の姿をした辻斬りが、夜の町を歩いている」
- 2/タイトル「第五話 偽りが偽りを斬る」

## P2
- 1/寄合。謹慎を言い渡される狐白/重役「証はあるか」/狐白「……ありません」
- 2/詰所の土間。無言で刀を差し出す蛇ノ目/ナレ「預かるとは、そういう意味だった」

## P3
- 1/自室。膳の上に並べた割れた白狐面
- 2/面の割れ目のアップに重なる宵霞の声(フラッシュ)「偽りを纏って生きるのは、楽だろう」
- 3/モノローグ「面の下に隠してきたのは顔ではない。妹に言えない秘密と、素顔への怯えだ」

## P4
- 1/障子の外の爪音。結び文をくわえた白い小狐
- 2/(大ゴマ)咲耶の文。『信じています。あなたは目が見えないのに、刀を私と反対側に置き直しました。辻斬りにそれはできません』
- 3/文を握る手/『今夜、河原の桜の下で。二人だけで終わらせましょう』

## P5
- 1/モノローグの転回(白背景に狐白の立ち姿)「半拍だけ世界を欺く——何のために」
- 2/イメージ:偽りの半拍の裏で生き延びる誰か/「あの半拍は、守るものがある者の時間だ」
- 3/面の片割れだけを懐に入れる(継がない)決意の手元

## P6
- 1/夕暮れの詰所前。蛇ノ目「謹慎中だぞ」「……夜露は体に毒だ。早く帰れよ」/背を向ける
- 2/七分咲きの夜桜と月。河原に立つ「もう一人の狐白」

## P7(山場)
- 1/(大ゴマ)白狐面・風魔装束・同じ背格好の偽狐白。内側から宵霞の声「どちらが本物か、世界はもう知らん」
- 2/素顔で歩み出る狐白「世界は知らなくていい。俺が知っている」
- 3/「その姿は俺じゃない。俺は今夜、面を着けていない」/同時抜刀/SE:チャキン×2

## P8(見開き級・鏡の殺陣)
- 1/(見開き)桜吹雪の中、同じ太刀筋同士が火花を散らす鏡合わせの構図/SE:ギィン ギン
- 2/五合目、狐白の気づき(目のアップ)「お前の写しは、皮一枚だ」
- 3/乱れる偽狐白の剣。踏み込んで峰で面を打つ/SE:パァンッ

## P9
- 1/割れ落ちる偽の白面。剥がれる写し、月に晒される宵霞の素顔
- 2/空蟬が飢えたように鳴る/宵霞「次で終いだ。三日後の満月、この河原で」
- 3/溶ける気配。追わない狐白

## P10(引き)
- 1/桜の陰から出る咲耶。偽の面を拾い、彼の素顔を見て笑う「うん。やっぱり、そっちのほうがいい」
- 2/(ラスト)夜風に頬を晒す素顔の狐白。懐の面の片割れに触れる手/ナレ「満月まで、あと三日」/次話へ
