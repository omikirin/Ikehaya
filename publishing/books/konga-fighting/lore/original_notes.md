# 本作独自解釈(二次創作オリジナル要素)

- 敵「鵺垣玄骨(ぬえがき・げんこつ)」は本作オリジナルの用心棒。根の国の残り香(封印の隙間から漏れた negativeな気)を喰らって肉体を岩のように硬化させる、公式に存在しない人物。
- コンガの過去: 若い頃、力任せの拳で仲間を守れなかった経験があり、以後「教える側」に回った——という背景は本作の創作。
- 影分身の運用「自分自身と殴り合う修行」: 影分身は術者と同じ技量・同じ癖を持つ、という解釈は本作独自。分身を維持しながら殴り合うと体力と気を二重に消耗する、という代償設定も本作独自。
- 甲賀の稽古場「拳の庭」、宿場町「戸隠宿」、祭「秋分の奉納試合」は本作オリジナルの舞台装置。
- くのいち見習い「小雨(こさめ)」、兄弟子「轟(とどろき)」は本作オリジナルのキャラ。
- 甲賀の口伝「影は写し。写しは実より雄弁なり」は本作の創作。
- シャオラン・咲耶の登場場面はいずれも味方・同門としての範囲で、公式設定(口寄せ・太極拳・手裏剣)のみ使用。
