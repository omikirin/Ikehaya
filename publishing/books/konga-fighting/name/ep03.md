# ネーム 第3話 影は嘘をつかない(全10ページ)

## P1
- 1/夜明け前の自室、晒し姿で起き上がるコンガ/効果音: ズキ…
- 2/モノローグ「三日。弟子に担がれて帰る師範を、誰も責めなかった。それが一番堪えた」
- 3/暗い拳の庭に立つ影/効果音: ヒュウ(風)

## P2
- 1/咲耶、薬草を縁側に置く/セリフ「無茶よ。肋骨、まだくっついてない」
- 2/セリフ「祖父に相談する? 伊賀に助っ人を——」
- 3/コンガの強い目のアップ/セリフ「駄目だ。あれは、拳の話だ」

## P3
- 1/咲耶「小雨ちゃんのため?」
- 2/コンガ正面/セリフ「俺のためだ」
- 3/去る咲耶の背中。小さく微笑/演出: 無言

## P4
- 1/一人の庭。玄骨の言葉が文字演出で降る「緩めてやがる」「怖えんだろ」
- 2/自分の拳を見つめる/モノローグ「二十年、最後の一寸で必ず減速する。弟子を壊さない拳。その同じ癖が——迷いになる」
- 3/ハッと顔を上げる/セリフ「癖は、自分じゃ見えねえ。……なら、見ればいい。外から」

## P5
- 1/大ゴマ: 印を結ぶ手/効果音: バッ
- 2/朝靄が渦を巻き、影が立ち上がる/効果音: ゴォォ…
- 3/もう一人のコンガ、完成/効果音: ドン

## P6
- 1/向き合う二人のコンガ/セリフ「なあ、おい。俺と、殴り合え」
- 2/分身、ニヤリと構える/演出: 目の奥にわずかな怯え
- 3/コンガの背筋に冷たい汗/モノローグ「これが、俺か」

## P7(見開き・山場)
- 1/見開き大ゴマ: 二人のコンガの拳が正面から噛み合う/効果音: ゴッ!! バキッ!!
- 2/端コマ: 折れた肋骨に響く/効果音: ズキィ/モノローグ「分身を保ったまま打ち合う——一発が、二発分」

## P8
- 1/スロー演出: 分身の拳が当たる寸前わずかに緩む、円で強調/モノローグ「見えた」
- 2/膝が半寸引ける、円で強調/モノローグ「これが二十年分の、俺の逃げか」
- 3/血の味の口で笑うコンガ/セリフ「はは……」

## P9
- 1/日々のモンタージュ: 殴られる→癖が消える→速くなる/モノローグ「おのれを削って、おのれを鍛える。これほど正直な修行はない」
- 2/六日目の夜明けの光/効果音: サァァ

## P10(引き)
- 1/分身の顔に影が差す大ゴマ。同じ顔なのに「あの夜」の表情/効果音: ゾクッ
- 2/分身の口元アップ/セリフ「思い出せよ。てめえが、誰を壊したのか」
- 3/黒ベタに白抜き文字「影は、嘘をつかない」/次話へ
