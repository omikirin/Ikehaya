# ネーム 第2話「分身は無口がすぎる」(全10ページ)

## P1
- 1/ 地図風俯瞰: 里の学園と山向こうの塾、二本の点線ルート。/ ナレ「作戦は単純だった」
- 2/ 学園の戸口、挨拶成功する分身。/ 分身「雑賀から来ました。凪紗です」
- 3/ 山道を走る本体、なぜかドヤ顔。/ モノローグ「誇らしかった」

## P2
- 1/ 教室、新入りを囲む生徒たち。/ 生徒「どこから来たの?」「密偵ってほんと?」
- 2/ 波四回分の間(コマ内に波の小絵4つ)。/ 分身「……たぶん」
- 3/ ざわつく教室。/ 生徒「密偵が『たぶん』…」/ 演出: 半刻後「なんか面白いやつ」認定

## P3
- 1/ 風太登場、徳利を振る。/ 風太「よーし新入り。忍びが一番大事にすべきもんは何だ?」
- 2/ 立ち上がる分身、口を開閉。/ 効果音: しーん
- 3/ 分身の頭の中(白米の妄想が渦巻く)。/ 演出: 湯気

## P4(山場1)
- 1/ 大ゴマ: 分身「……飯」
- 2/ 教室大爆笑。/ 効果音: どっ!!
- 3/ 黒板に大書する風太。/ 風太「正解にしとこう! 腹が減っては戦はできぬ!」
- 4/ 小コマ: 「飯の凪紗」爆誕。/ ナレ「以後そう呼ばれる」

## P5
- 1/ 場面転換・山の塾。岩を拳で割るコンガ。/ コンガ「わたしがコーチのコンガである!」/ 効果音: ゴッ!!
- 2/ 走る跳ぶ走る本体、白目。/ 効果音: ぜぇぜぇ
- 3/ コンガ「声が小さい!」/ 本体「は……はいっ」

## P6
- 1/ 大ゴマ: 本体、人生最大の声。/ 本体「はいっ!!」/ 演出: 集中線
- 2/ 驚くくのいちたち。/ 本体、頬を赤らめる。
- 3/ 巻物に「合格」と大書するコンガ。/ 本体、喘ぎながら小さく笑う。

## P7
- 1/ 昼餉。たくあんをくれるくのいち。/ くのいち「雑賀の子、足速いね」/ 本体「……密偵、なので」
- 2/ 巻物の隅アップ「甲賀のたくあん、うまい」。
- 3/ 稽古の締め、コンガの訓示。/ コンガ「観察と機転と、胆力である!」

## P8(山場2・ドタバタ)
- 1/ 夕刻の里の道。角を曲がる本体。
- 2/ 大ゴマ: 正面から歩いてくるもう一人の自分! / 二人「っ!?」/ 効果音: ばっ!!
- 3/ 民家の陰に同時に飛び込む二人。/ 効果音: ダッ

## P9
- 1/ 横長コマを縦線で2分割し左右対称に: 本体は右を指差し、分身は左を指差す。真ん中で指先が交差。二人とも大真面目な顔(3ポーズ指定: 指差し→交差に気づく→同時に指を引っ込める、の小3コマでも可)。/ 効果音: ビシッ ビシッ
- 2/ 一拍遅れて頷く分身、右へ走る。
- 3/ 通りかかる犬の柴、右を見て、左を見て、首をかしげる。/ 柴「くうん?」

## P10(引き)
- 1/ 岩陰、術を解く。記憶流入(「飯」の場面がフラッシュ)。/ 本体「~~~っ」
- 2/ 砂浜で反省の巻物を書く凪紗。/ 巻物「一。分身に握り飯を持たせること」
- 3/ 引き: 月夜、遠くに猫又のシルエット、光る目。/ 煽り「見ている者がいた」
