# ネーム 第4話「猫又、抜き打ち検査」(全10ページ)

## P1
- 1/ 学園門前の貼り紙アップ。/ 貼り紙「本日、抜き打ち風紀検査を行う。検査役・猫又」
- 2/ 一拍遅れて青ざめる分身。/ 効果音: ぞくっ
- 3/ 同刻、山道の本体の背にも汗。/ モノローグ「まずい予感まで共有してしまう」

## P2
- 1/ 検査項目の立て札(三項目)。/ 「一、持ち物検査」「二、昨日の夕餉」「三、中庭にて茹で蟹の振る舞い(希望者のみ)」
- 2/ 三つ目を指す矢印+ドクロ演出。/ ナレ「三つ目が罠であることは明白である」
- 3/ 分身の腹の音。/ 効果音: ぐぅ…

## P3
- 1/ 列に並び猫又を観察する分身(視線の分析線)。/ モノローグ「猫又が見ているのは、答えるまでの『間』だ」
- 2/ 前の生徒がしどろもどろで捕まる小コマ。/ 猫又「つまみ食いじゃな」
- 3/ 分身、静かに息を整える。/ モノローグ「間を、乱さないこと」

## P4
- 1/ 分身の番。/ 猫又「巻物、開けい」
- 2/ 巻物検分の大ゴマ(端から端まで)。/ 効果音: するする…
- 3/ 猫又「ふん」/ 分身、無表情(内心は冷汗)。

## P5
- 1/ 猫又「昨日の夕餉は」/ 分身「……鰯の丸干しと、麦飯」
- 2/ 猫又の髭がぴくり。/ モノローグ「正確すぎたのかもしれない」
- 3/ 猫又「最後じゃ。蟹、食うていけ」/ 効果音: ドーン(湯気の立つ蟹)

## P6(見開きの山場)
- 1/ 見開き大ゴマ: 豪華な蟹の皿(甲羅と太い脚がこちら向き)VS 分身。腹の虫が鳴きかける。/ 効果音: ぐ…
- 2/ インサート・巻物の一行「猫又どのは、検分したいときだけ一番よい部位を相手に出す」
- 3/ 分身、深々と一礼。/ 分身「……修行中の身、ゆえ。美食は、修了してから」

## P7
- 1/ 猫又の尻尾がぱたりと落ちる。/ 猫又「……見上げた心がけじゃ」
- 2/ 小コマ: 立ち会いの犬の柴、分身の袖をすん、と嗅いで首をかしげる。猫又を見て、何も言わず伏せ(台詞なし。第6話「匂いが二人分」の伏線=T-5)。/ 効果音: すん…
- 3/ すれ違いざま、小声。/ 猫又「無理はするなよ、小娘。腹が減ったら、いつでも食いに来い」
- 4/ 一拍遅れて振り返る分身。猫又はもう次の生徒へ。

## P8
- 1/ 山の稽古場、受け身を続ける本体。/ コンガ「続けい!」
- 2/ モノローグ「ここで倒れれば、山向こうの分身ごと倒れる」
- 3/ 昼下がりの教室、分身の輪郭がすうっと薄く…光が肩を通り抜ける。/ 効果音: すぅ…

## P9
- 1/ 目をこする隣の生徒。
- 2/ 柱の影に隠れる分身。/ 分身「密偵の気配遮断です」
- 3/ 教室「さすが飯の凪紗」/ 効果音: おおー(妙な納得)

## P10(引き)
- 1/ 夕刻の浜、握り飯を三つ食う本体、指が震えている。
- 2/ 触れ書きを写す手が止まる。/ 巻物「学園——霜月一日、朝五ツ」「塾——霜月一日、朝五ツ」
- 3/ 引きの大ゴマ: 呆然と海を見る凪紗、二枚の触れ書きが風にはためく。/ 煽り「修了試験、同日同刻」
