# ネーム 第5話「試験、二会場同時進行」(全10ページ)

## P1
- 1/ 夜明け前の浜、印を結ぶ凪紗。/ ナレ「霜月一日」
- 2/ 立ち上がる分身(もう堂々としている)。/ 本体「……学園、頼む」/ 分身「……塾は、任せた」
- 3/ 別れ際。/ 分身「……終わったら、蟹、食べたい」/ 本体、ふっと笑う。

## P2
- 1/ 太鼓が山と里で同時に鳴る(2分割対称コマ)。/ 効果音: ドン! ドン!
- 2/ 学園会場、問題を見て固まる分身。/ 風太「予定変更だ! 実技を含む総合試験!」
- 3/ 塾会場、まっさらな長い紙を前にする本体。/ コンガ「伝統により筆記! 十八日間の観察をすべて書け!」

## P3
- 1/ 大ゴマ: 左右対称に青ざめる本体と分身。/ ナレ「完全に、逆だった」
- 2/ 本体、筆を握り直す。/ モノローグ「密偵は、想定が崩れてからが本番だ」
- 3/ モノローグ「——大丈夫。わたしは、二人いる」

## P4
- 1/ 交換案・棄権案が浮かんで消える(バツ印演出)。
- 2/ 二人同時にひらめく(左右対称)。/ モノローグ「書けばいい。読めばいい」
- 3/ 術の糸のイメージ(山を越えて繋がる光の線)。/ 効果音: ピン…

## P5(見開きの山場・前半)
- 1/ 見開き大ゴマ: 画面を対角線で二分。左=巻物を机の下で開く分身、右=その文字を写し取る本体。中央に術の糸。/ 効果音: サラサラサラ
- 2/ 柴、目を丸くする。/ 柴「棒立ちだったやつが……化けたな」(分身が受け身を決める小コマ)

## P6
- 1/ 負荷の描写: こめかみに汗、視界が二重にぶれる演出。/ モノローグ「右手と左手で別々の手紙を書きながら、歌を歌うようなもの」
- 2/ 文字が揺れる答案アップ。
- 3/ 効果音: みしっ…(限界の音)

## P7(混線ギャグ)
- 1/ 本体の答案アップ。/ 「忍びが一番大事にすべきものは、飯」
- 2/ 分身の答案アップ。/ 「霜月一日の献立。鰯の丸干し、麦飯」
- 3/ 二人同時に「!?」(左右対称)。/ モノローグ「どちらの脳がどちらの筆を…」

## P8
- 1/ 塾会場の戸が開く。/ 効果音: からり
- 2/ 大ゴマ: 湯気の立つ蟹を抱えた猫又、満面の笑み。/ 猫又「甲賀まで来てやったぞ、凪紗ァ! 蟹、食え!」
- 3/ ナレ「悪気は、ひとかけらもなかった」

## P9
- 1/ 蟹の香りが会場に満ちる(香りの線が本体を包む)。
- 2/ 大ゴマ: 腹の音が太鼓より大きく鳴る。/ 効果音: ぐうううぅ!!
- 3/ 集中の糸が切れる演出(光の線がぷつん)。/ 効果音: ぷつん

## P10(引き)
- 1/ 学園会場、答案を書く分身の手が止まる。
- 2/ 引きの大ゴマ: 試験会場のど真ん中で、分身の輪郭がゆらりとほどけ始める。生徒たちが振り返る。/ 効果音: ゆら…/ 煽り「十八日間の綱が、切れる」
