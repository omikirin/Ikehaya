# ネーム 第6話「二枚の巻物」(全12ページ)

- 2/ 分身、最後の力で背筋を伸ばし、深く一礼。
- 3/ 分身「……ごめん、なさい」/ 演出: 影が静かに消える。/ 効果音: ふ…

## P2
- 1/ 塾会場、机に突っ伏す本体。記憶の流入(皆の驚いた顔がフラッシュ)。
- 2/ モノローグ「終わった。全部、ばれた」
- 3/ 近づく猫又の足音。/ 効果音: ひた…ひた…/ 本体、顔を上げられない。目の縁に涙。

## P3
- 1/ 猫又「……よう保ったのう」(意外なほど優しい声)。
- 2/ おそるおそる顔を上げる本体。猫又は感心顔で髭を揺らす。
- 3/ 猫又「影分身を十八日、途切れさせなんだ。わしでも三日で音を上げるわ」
- 4/ 本体「……気づいて、いたんですか」/ 猫又「初日からじゃ」

## P4
- 1/ 戸口から三味線の音。/ 効果音: ぽろん
- 2/ 大ゴマ: 弁天登場。後ろに風太と犬の柴。/ 弁天「わたしの書類仕事に、手違いなんぞあるものかい」
- 3/ 呆然の本体。

## P5(種明かし)
- 1/ 回想: 二枚目の願書を見た瞬間の弁天(全部お見通しの顔。第1話P3-3と同じ目のアップの反復=K-6)。
- 2/ 弁天「腕は確かなのに、いざという時に声が出ない。それが密偵として命取りになる」
- 3/ 無言のコマ: 凪紗の手元。膝の上で握りしめられた二枚の巻物(T-2の間。種明かしのセリフ連続をここで一度切る=K-4)。/ (無言)
- 4/ 弁天「じゃから、試した。おまえさんがどう切り抜けるか、皆で見届けようとな」

## P6
- 1/ 風太「『飯』の答えは学園の語り草だぜ」(笑)
- 2/ 柴、人型に変化。/ 柴「途中から体術が急に上手くなったのも、そういうことか。……匂いが二人分あったのも、な」
- 3/ 小コマ・窓外の海。波の音だけ。/ 効果音: ざざ…
- 4/ コンガ「肚から声を出せと言うたのは、今日この日のためである!」/ 効果音: ドン

## P7(左ページ・見開きへの溜め)
- 1/ 弁天、撥を凪紗に向ける。/ 弁天「手心はひとつも加えとらん。十八日凌ぎきった忍びは、雑賀の歴史にもおらん」
- 2/ 凪紗の中で十八日間が色を変えるイメージ(綱渡りの綱の下に、皆の手で張られた網)。
- 3/ 小コマ: 浅い呼吸。凪紗の口元だけ。/ (無言)
- 4/ 小コマ: 息を、深く吸い直す(左ページ最終コマ=めくりの引き・K-1。コマを刻んで溜める=K-2)。/ 効果音: す……

## P8-9(見開き・対向2ページ・山場)
- 1/ 見開き大ゴマ(P8-9の対向2ページで組む。凪紗を中央やや右、皆の言葉はノドを避けて左右の空に配置): 立ち上がる凪紗。深呼吸。周囲に皆の言葉が浮かぶ(「ゆっくりでいいぞう」「肚から声を出せ」「無理はするなよ」「忍びは奥が深いな」)。
- 2/ (P9下段)凪紗「……間違いを、言い出せませんでした。ごめんなさい」
- 3/ (P9下段)凪紗「でも……二つの学校に、行けてよかった。……どっちも、修了したいです」

## P10
- 1/ しん、とした間(2拍分の無音コマ)。
- 2/ 大ゴマ: 弁天の三味線が祝いの調子で鳴る。皆の笑顔。/ 効果音: べべん!
- 3/ 掲示板: 学園の欄に「凪紗」、塾の欄にも「凪紗」。/ ナレ「里はじまって以来の二重修了」

## P11
- 1/ 授与式、二枚の修了巻物を受け取る凪紗。
- 2/ 祝いの席、大鍋の蟹。頬張る凪紗、囃す風太。/ 風太「飯の凪紗、蟹も強い」/ 効果音: どっ
- 3/ 凪紗、俯かず小さく笑い返す。

## P12(ラスト・ほろり)
- 1/ 夕陽の浜。印を結ぶ凪紗、分身が立ち上がる。
- 2/ 二枚の巻物を見せる。/ 本体「……やったね」/ 分身「……うん」
- 3/ 引きの大ゴマ(ラスト): 一拍遅れて、確かに笑う分身。並んで続く二人分の足跡と夕陽の海。/ 効果音: ざざーん/ ナレ「波が寄せて、返した」
