# 本作独自解釈ノート(oto-sports)

本作は既刊『uka-dark-fantasy』とは**独立した並行世界**として書く。同一キャラでも設定・出来事の整合は取らず、矛盾は意図的に許容する。

## 独自設定(公式にない要素)
1. **クラン対抗「御前試合」**: シーズン2の平和な時代に、4クラン合同で年に一度開かれる武芸試合。殺し合いではなく技を競う競技(スポ根の舞台)。里の長老たちが立会人。完全に本作オリジナルの行事。
2. 於兎の人物像: 「天才」と呼ばれ続け、負けを知らない少女。勝ち続けることの孤独と、称賛が壁になっていく感覚を抱えている——性格の掘り下げは本作独自。
3. 於兎の口寄せの運用: 巻物に複数の兎(月白・玄・葉月など兎たちの名は本作オリジナル)を封じ、状況で使い分ける。口寄せの代償として「術者の体温と気力を兎に分け与える」設定は本作独自。
4. 宇迦の九尾の焔の運用: 護符を媒介に狐火を段階解放する描写は本作独自。効果は公式記述(狐を使役・九尾の焔)の範囲内で盛らない。
5. 敵役: 公式キャラを悪役にしない。試合の相手やオリジナルの門下生(甲賀の下忍・時雨など)は本作オリジナル。
6. イズナが妹・宇迦を見守る描写、岩爺が立会人を務める描写は、公式の関係性(姉妹・長老格)の範囲での独自肉付け。

## 方針
- 全年齢。性的描写・過度なゴアなし。
- 熱く、最後は爽やかに。「勝ち続ける者の孤独」が軸。
