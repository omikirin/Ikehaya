# ネーム 第3話 焔の背中(全8ページ)

## P1(扉)
- コマ1: 中日の観客席、笠を目深にかぶる於兎。屋台の喧騒。/ SE: ワイワイ
- コマ2: タイトル「第3話 焔の背中」
- コマ3: 「隣、いい?」と干し芋を差し出すイズナ。

## P2
- コマ1: 並んで座る二人。/ イズナ「笠かぶってても分かるよ。姿勢が良すぎるもん」
- コマ2: イズナの横顔。「あの子さ、今朝、飯を三杯食ったんだよ」
- コマ3: 舞台上の宇迦と伊賀の拳士が向かい合う。/ アナウンス「準々決勝!」

## P3
- コマ1: 拳士が疾風のように突進。/ SE: ダッ
- コマ2: 動かない宇迦、指先で護符を一枚抜く。/ セリフ「九尾の焔——一の尾」
- コマ3: 肩口に灯る狐火。/ SE: ボッ

## P4〜5(見開き・山場)
- コマ1(見開き大): 増えた狐火が群れ狐の動きで拳士を包囲していく俯瞰。/ SE: ゴオオ
- コマ2: 観る於兎の目、見開かれる。/ モノローグ「火力じゃない。数と動きで盤面を支配している」
- コマ3: 自分の眼前で護符を焚き、光で目を灼いて掌打を突く宇迦。/ SE: カッ! ドッ!
- コマ4: 「勝者、甲賀・宇迦!」

## P6
- コマ1: 汗を拭い、まだ足りないと掌を見つめる宇迦。
- コマ2: 胸を押さえる於兎。/ モノローグ「恐怖じゃない。……早くあの焔と、跳び比べたい」
- コマ3: イズナ「いい顔するようになったね、あんた」

## P7
- コマ1: イズナの回想語り(小コマ): 歓声の中、迷子の顔で立つ昔の於兎。/ イズナ「歓声のど真ん中で、独りぼっちの顔」
- コマ2: 「あの子はあんたに勝つためだけに九年、護符を灯し続けた」
- コマ3: 去り際、笠の縁を叩くイズナ。「あれはね、あんたにしか使わないつもりだよ」

## P8(引き)
- コマ1: 於兎の視線が宇迦の腰元へ(視線誘導の細長コマ)。
- コマ2(大ゴマ・アップ): 護符の束の奥、一枚だけ金色の九枚目の札。/ SE: ゾクッ
- コマ3: 背筋を撫でる予感に、しかし口元は笑う於兎。/ モノローグ「九尾——」/ 次話へ
