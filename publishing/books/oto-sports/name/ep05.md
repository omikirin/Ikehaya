# ネーム 第5話 前夜(全8ページ)

## P1(扉)
- コマ1: 夜。提灯の落ちた静かな里を歩く於兎。/ モノローグ「決勝前夜。目は冴えるばかりだった」
- コマ2: タイトル「第5話 前夜」
- コマ3: 月明かりに洗われた無人の試合場。

## P2
- コマ1: 舞台中央に座る先客。護符を検分する宇迦。/ 宇迦「……眠れないの、天才も」
- コマ2: 少し迷って、隣に腰を下ろす於兎(二人の距離を強調する引きの構図)。
- コマ3: 虫の声。沈黙。/ モノローグ「九年ぶりに隣に座って、話す順番を探していた」

## P3
- コマ1: 於兎「昼間の応援。敵にすることじゃないでしょ」
- コマ2: 護符から顔を上げない宇迦。「応援じゃない。予約。あんたを倒すのは、あたし」
- コマ3: 「九年待ったんだから」/ 月を見上げる二人。

## P4
- コマ1: 於兎、月を見たまま。/ セリフ「あのとき——わたしは、友達を一人なくしたと思ってた」
- コマ2: 宇迦の指が止まる(手元アップ)。
- コマ3: 於兎「天才って呼ばれるのは、独りって呼ばれるのと同じだった」

## P5
- コマ1: 沈黙ののち、堪えきれず笑い出す宇迦。「……なにそれ。ばっかじゃないの」
- コマ2: 笑いながら少し涙ぐむ宇迦。「あたしの九年、返してよって話じゃん」
- コマ3: 「追いかける方だって、独りなんだよ」

## P6
- コマ1(回想小コマ): 夜の川原、一人で護符を灯しては消える狐火を見つめる宇迦。/ SE: ボッ……フッ
- コマ2: 「気づいたら、九枚灯せるようになってた」
- コマ3: 於兎「この寒さを分かる人は、どこにもいないと思ってた。……いたんだね。すぐ隣の稽古場に」
- コマ4: 月光の下、板張りに並ぶ二つの影(七つの頃の影とオーバーラップ)。

## P7(山場)
- コマ1: 立ち上がり、月を背にする宇迦(逆光、目だけ焔のように)。/ セリフ「あんたが勝ち続けてくれたから、あたしの九年は嘘にならない」
- コマ2(大ゴマ): 月光にかざされる護符の束。八枚の朱と、一枚の金。/ セリフ「明日、全部ぶつける。受け止めてよ、於兎」
- コマ3: 立ち上がる於兎。「うん。全部、受け止める。そのうえで——勝つのは、わたし」

## P8(引き)
- コマ1: 七つの頃と同じ顔で笑い合う二人。
- コマ2: 宿舎。枕元の巻物にそっと触れる於兎。/ セリフ(小)「明日は、全部出すよ。付き合ってね」
- コマ3(大ゴマ): 夜明け前の空。/ モノローグ「生まれて初めて、負ける想像が怖くなかった」/ 次話へ
