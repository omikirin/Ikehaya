# プロット — 兎は月を独りで跳ぶ

## ログライン
天才と呼ばれ勝ち続けてきた甲賀の少女・於兎が、クラン対抗御前試合でライバル宇迦と再び相まみえ、「勝ち続ける者の孤独」の正体と、勝負の先にある喜びを知る物語。

## 三幕構成
- 第一幕(1〜2話): 御前試合の開幕。無敗の天才・於兎は、称賛されるほど周囲との間に透明な壁を感じている。宇迦との再戦の予感。
- 第二幕(3〜5話): 勝ち上がる於兎だが、口寄せの代償が身体を蝕み、孤独が術を鈍らせる。宇迦もまた「天才の背中を追う者」の苦しみを抱えていたと知る。
- 第三幕(6話): 決勝、於兎対宇迦。全てを出し切る死力の攻防の果てに、於兎は初めて「独りではない勝負」を知る。勝敗を越えた爽やかな結末。

## 全6話
1. **無敗の兎** — 御前試合開幕。於兎は初戦を圧勝するが、観客の歓声が遠く聞こえる。控えの間で宇迦と目が合う。/ 引き: 「次に当たるとしたら、決勝だね」
2. **透明な壁** — 幼少期の回想。初めて宇迦に勝った日から、友は「挑戦者」に変わった。二回戦、雑賀の射手(オリジナル門下生)との遠近戦。/ 引き: 勝った手が、微かに震えていた。
3. **焔の背中** — 宇迦の準々決勝を観戦する於兎。九尾の焔の完成度に、初めて「追われる恐怖」ではなく「昂ぶり」を感じる。/ 引き: 宇迦の護符に、見たことのない九枚目の札。
4. **代償** — 準決勝、風魔の口寄せ使い(オリジナル門下生)との消耗戦。兎に体温を分け与えすぎ、於兎は倒れかける。イズナの言葉。/ 引き: 「あんたが独りで勝ってきたと思ってるのは、あんただけだよ」
5. **前夜** — 決勝前夜。眠れぬ於兎と宇迦が月下で語る。追う者と追われる者、互いの孤独が初めて言葉になる。/ 引き: 「明日、全部ぶつける。受け止めてよ、於兎」
6. **月と焔** — 決勝。兎の白と狐火の朱が舞台を染める死力の攻防。代償の果てに於兎が掴んだのは、勝敗ではなく「同じ高さで跳ぶ相手」。爽やかな幕引き。

## 主役の内的変化
「勝つことでしか自分を保てない孤独な天才」→「ライバルという鏡を得て、勝負そのものを愛せる者」へ。歓声が遠かった耳に、最後は宇迦の声だけが真っ直ぐ届く。
