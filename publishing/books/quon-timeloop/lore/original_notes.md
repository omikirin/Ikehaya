# 本作独自解釈(二次創作としての創作部分)

公式設定と矛盾しない範囲での、本作オリジナルの解釈・追加要素。

1. **「猫の目の選択」の解釈**: 公式では「幸福な未来を選び取る能力」。本作ではこれを「猫の瞳孔が光で細くなるように、無数に枝分かれする人生の分岐(選ばれ得た生)を視て、その中から一本を選び取る術」と解釈する。選ばれなかった分岐は消えず、「陽炎の路(かげろうのみち)」として久遠にだけ視え続ける——これは本作独自の設定。
2. **長命種としての久遠**: 公式の未確定メモにある「久遠やアトザなど長命種の過去デザイン案」を創作の余白として使用。本作では久遠を、幾つもの時代を生きてきた長命の存在として描く。具体的な年齢・出自の細部は公式未確定のため、すべて本作の創作。
3. **鬼火の解釈**: 武器「鬼火」を、選ばれなかった分岐の残り火=「あり得た生の燃えさし」を灯す火と解釈。鬼火を掲げると陽炎の路へ「渡る」ことができる、という時間ファンタジー装置は本作独自。
4. **代償の設定**: 陽炎の路へ渡るたび、久遠自身の「選んだ生」の記憶が一つずつ薄れていく、という代償は本作独自。効果を公式より盛らないためのブレーキとして機能させる。
5. **オリジナルの敵**: 敵役「虚ろ日(うつろび)」は本作オリジナルの存在(選ばれなかった分岐に溜まった未練が凝った影)。公式キャラを悪役にしない方針に従う。根の国の公式キャラは登場させない。
6. **猫又との過去**: 「同じ里の出身で久遠が年上」という公式関係のみを土台に、幼い猫又を久遠が見守っていた過去エピソードを創作。
7. **時代設定**: シーズン2(平和な時代)の雑賀の里を現在地とし、久遠の記憶と陽炎の路を通じて過去(S1相当の戦乱の記憶)にも触れるが、公式の歴史的出来事(根の国封印など)の描写は改変しない。
