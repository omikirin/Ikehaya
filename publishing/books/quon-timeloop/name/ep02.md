# ネーム 第2話 陽炎の路(全9ページ)

## P1
- 1/朝の里。歩き回る久遠/モノローグ「黒いのは、小夜だけだ」
- 2/すれ違う里人たちの頭上に、正常な光の扇が次々開く(小ゴマ3連)
- 3/久遠、立ち止まる/久遠「毒でも祟りでもない。路そのものが、塗られておる」

## P2
- 1/寺の書庫。巻物を繰る久遠の手元/効果音: パラ…
- 2/鬼・悪霊・祟り神の挿絵が並ぶ古文書(コマ内資料風)
- 3/久遠、書を閉じる/モノローグ「あやかしは人の『いま』に憑く。未来の全部を塗る筋は、どこにもない」/久遠「ならば——この世の外だ」

## P3
- 1/夕刻の縁側。黙って隣に座る猫又/猫又「顔が、渡る前の顔をしています」
- 2/久遠(とぼけ)「わしに渡る前の顔などあったか」
- 3/猫又、正面から/猫又「あります。婆さまの葬式の年と、大水の年と」

## P4(術と武器の説明)
- 1/回想調の大ゴマ。掌の上で伸び上がる青い鬼火/モノローグ「鬼火——刃でも毒でもない。選ばれなかった生の燃えさし」
- 2/鬼火の芯に「知らない自分の顔」が揺れる/効果音: ゆら
- 3/現在に戻り、猫又「小夜のことですね。俺も行きます」

## P5
- 1/久遠、首を振る/久遠「あそこは選ばれなかった側の世界よ。おまえには踏む地面がない」
- 2/猫又、目を鋭く/猫又「……代償があるのでしょう」
- 3/沈黙の間。夕日の縁側、二人の影が長い

## P6(代償の明示)
- 1/久遠の顔、半分影/久遠「渡るたびに、忘れる。こちらで選んで生きた記憶が、一つずつ、路に喰われる」
- 2/回想小ゴマ: 仏前に飴を積む昔の久遠/久遠(回想外セリフ)「前は、婆さまの顔を置いてきた」
- 3/猫又「軽くなって、いつか空になったら」/久遠「わしが陽炎の側の住人になるだけだ」

## P7
- 1/猫又、懐紙の包み(焼き鰺)を押しつける/猫又「戻ったら、また焼きます。忘れたら、味で思い出してください」
- 2/久遠、受け取る手のアップ
- 3/風のない軒で風鈴が一度だけ鳴る/効果音: ちり

## P8(約束)
- 1/立ち上がる猫又、夕日で耳の先が赤い/猫又「全部忘れても、帰る路だけは忘れないでください」
- 2/猫又「帰ってくれば、あとは俺が片っ端から思い出させますから」
- 3/久遠、ただの年寄りの目で細める/久遠「……ふん。理屈だの」

## P9(見開き級の引き)
- 1/夜、豆腐屋の屋根。掌の鬼火が提灯大に伸び、闇に裂け目が開く/効果音: ゴ…
- 2/【最終ページの引き】大ゴマ。裂け目の向こうに無数の陽炎の路。踏み出す久遠の背中/久遠「三百年ぶりだの」/モノローグ「彼は、選ばなかった生へ、一歩を踏み出した」
