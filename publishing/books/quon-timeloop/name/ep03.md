# ネーム 第3話 術を捨てた男(全9ページ)

## P1
- 1/大ゴマ。夕日の段々畑。金色の稲。水車/効果音: ギイ…/モノローグ「一歩の先は、土の匂いだった」
- 2/掌の鬼火が豆粒サイズに縮んでいる/効果音: ちり…
- 3/空の一点に糸ほどの光(帰り路)/モノローグ「帰る路だけは、忘れるな」

## P2
- 1/畑で草を毟る男の背中
- 2/振り向く男——久遠と同じ顔。ただし瞳孔が丸い(対比を強調)/畑の久遠「珍しい客だの」
- 3/向き合う二人の久遠(同ポーズの鏡像構図)/畑の久遠「こちらへ渡るのは、術を持ったままの側のわしか」

## P3
- 1/久遠「……おまえは、捨てた側か」
- 2/畑の久遠、遠い目/畑の久遠「若い時分、視えるのが嫌になった。誰の顔もまともに見られん」
- 3/回想小ゴマ: 目を閉じる若い久遠/畑の久遠「ある朝、二度と絞らんと決めた。それだけの分かれ道よ」

## P4
- 1/囲炉裏。粥を炊く男。久遠は客の座/効果音: くつくつ
- 2/位牌と欠けた木の匙のアップ/畑の久遠「妻がいた。四十年、共に耕した」
- 3/久遠、椀を持つ手が止まる

## P5(哲学の芯・その1)
- 1/久遠「幸福か」
- 2/畑の久遠、笑う/畑の久遠「視えんからな、確かめようがない。だが存外、良いものだぞ」
- 3/畑の久遠「明日が分からんから、今日、水をやる。それで一日が終わる」
- 4/久遠の目のアップ。揺れる/モノローグ「わしが選んできた『幸福』とは、何と比べての幸福だったか」

## P6
- 1/妻の思い出を語る男(回想: 泣く妻の背中)/畑の久遠「おまえは本当は視えるのに、わしのために閉じたのではないかと」
- 2/畑の久遠「閉じたからおまえに会えたのだ、と答えた。順序が違えば、意味は違う」
- 3/囲炉裏の火が爆ぜる/効果音: パチ

## P7
- 1/粥のお代わりをよそぐ男/畑の久遠「選び取られなかったものの置き場を、おまえは知っておったか」
- 2/久遠、鬼火を見る/久遠「……懐に、抱いてきた。燃えさしにしてな」
- 3/畑の久遠「なら、わしよりは幾らかましな置き場だ」

## P8(山場)
- 1/男、真顔で正面/畑の久遠「時に、術ありのわしよ」
- 2/【大ゴマ】畑の久遠「——して、今度は何を忘れてきた?」
- 3/久遠、答えられない。懐紙の包みの記憶が陽炎に揺れてほどける(演出: コマ自体が滲む)/久遠「……分からん」

## P9(引き)
- 1/戸口の外は夜。豆粒の鬼火が行く手を指す
- 2/畑の久遠、火を掻きながら背中で/畑の久遠「急げ。忘れたことを忘れる前にな。黒いのは路の奥におる」
- 3/【最終ページの引き】歩き出す久遠の背に、戸口からの声/畑の久遠「その目、呪いと思うなよ。——羨ましかったのは、わしのほうかもしれんのだ」
