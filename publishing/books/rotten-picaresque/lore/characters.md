# 公式設定要約(出典: NINJAMCP get_character / get_worldview)

## 呂屯(Rotten)#007 — 主役
- クラン: 風魔 / 忍術: 毒霧(Poison Mist) / 武器: 毒矢(Poison Arrow)
- 誕生日: 10月10日(世界ゾンビの日にちなむ)
- プロフィール: 風魔クランの幹部の一人で、アトザの配下として働く。名前の「Rotten」は英語で「腐る」を意味する。
- 関係: アトザ(#013)の部下。

## アトザ(Atoza)#013
- 風魔 / 忍術: 逢魔刻(Time for Disasters) / 武器: 棍棒 / 誕生日11月2日(いい鬼の日)
- 風魔クランを率いる首領格でありながら、実際は情に厚い一面を持つ。
- アウン(#029)の兄。呂屯(#007)・断(#010)を部下に持つ。シーズン1で岩爺(#016)たちと共に根の国を封印した。

## 断(Dan)#010
- 風魔 / 忍術: 閃光(Laser) / 武器: 閃光刀 / アトザの部下(呂屯の同僚)。

## 世界観(シーズン2=現代を舞台とする)
- 平和な時代。伊賀・甲賀・風魔・雑賀の4クランは大きな対立なく共存し、鬼や悪霊の退治、里のトラブル解決を担う。
- 根の国はシーズン1でアトザ・岩爺らにより封印済み。
