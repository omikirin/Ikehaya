# 本作独自解釈(公式にない要素の列挙)

- 呂屯の人物像の肉付け: 「風魔の汚れ仕事担当」を自称する皮肉屋。悪ぶるが、毒は常に「殺さない濃度」に調合してしまう癖があり、善行が漏れる愛すべき悪漢——これは本作の創作。
- 「腐れ屋(くされや)」という裏稼業の看板、毒の対価に「相手の悪事の証文」を取る流儀は本作オリジナル。
- 敵「宵蔵(よいくら)一家」: 里の薬種問屋を装い、偽薬と借金証文で村々を締め上げる盗賊まがいの商人一味。頭目・宵蔵仁兵衛とその用心棒集団はすべて本作オリジナルキャラ。公式キャラは悪役にしない。
- 毒霧の代償描写(使用後に自身の喉と指先が痺れる、味覚が数日死ぬ)は本作独自の設定。公式効果を盛らない範囲での制約付け。
- アトザが呂屯に非公式の「後始末」を任せる描写は、公式の「首領格・情に厚い」「呂屯は部下」の範囲内での解釈。
- 断との軽口の応酬(同僚関係の具体的な空気)は本作の創作。
- 舞台となる宿場「胡桃宿(くるみじゅく)」は架空の土地。
