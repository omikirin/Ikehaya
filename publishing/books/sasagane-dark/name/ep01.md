# ネーム 第一話 封じられた庭(全10ページ)

## P1
- コマ1/俯瞰・根の国全景。灰色の天蓋に覆われた闇の国/モノローグ「根の国に、季節は来ない」/効果音なし、静寂の演出(ベタ多め)

- コマ3/欄干に腰掛けるささがねの後ろ姿/モノローグ「封じられて、幾つの夜が過ぎたか」

## P2
- コマ1/手元アップ・指先から伸びる糸/モノローグ「糸の先には、何も掛からない」
- コマ2/ささがね横顔アップ/セリフ「……今宵も、空(から)かえ」

## P3
- コマ1/袖を引く小さな手(紫)/SE「くい」

- コマ3/椀の中の黒い澱アップ/セリフ「要らぬ。……それは、味がせぬ」

## P4
- コマ1/回想・封印前の里の夜(セピア調)。橋のたもとに立つ花魁姿のささがね/モノローグ「かつては、違った」
- コマ2/回想・糸に絡む淡い光(人の想い)/モノローグ「人の想いを啜って、妾は形を保ってきた」
- コマ3/回想・首を傾げる小僧の後ろ姿/モノローグ「啜られた者は、いちばん熱い想いを忘れる」

## P5
- コマ1/現在。水面に映る褪せた自分の顔/モノローグ「喰らわねば、妖は形を忘れる」
- コマ2/庭の底の闇。蠢く影(虚)のシルエット/SE「ずる…ずる…」
- コマ3/ささがねの目元アップ・冷たい視線/モノローグ「名も貌も失くした飢えの澱——虚(うろ)」

## P6
- コマ1/膝に頭を載せるヨミ、撫でるささがね/セリフ「妾はな、ヨミ」
- コマ2/優しくも寂しい微笑/セリフ「悪(わる)であることに、不服はないのじゃ」
- コマ3/回想イメージ・封印を張る地上の忍びたちの遠景シルエット(顔は描かない)/モノローグ「人の側からすれば、当然の始末よ」

## P7

- コマ2/ささがね、天蓋を仰ぐ/セリフ「退屈しのぎのひとつも、置いていってほしかったのう」
