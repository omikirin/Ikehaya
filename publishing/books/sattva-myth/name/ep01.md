# ネーム 第一話 白蓮の座(全9ページ)

## P1(扉)
- 1/俯瞰・雲海の上に浮かぶ白蓮の伽藍全景。/モノローグ「天界の朝は、鐘の音から始まる」/効果音「ゴーン…」余白多め、荘厳に。
- 2/池を渡る鐘の波紋のアップ。/なし/「ォォン…」

## P2
- 1/石座に坐すサットヴァ全身。頭上に円光。/なし/光輪に淡いトーン。
- 2/地上から昇ってくる青い魂の群れ、ロング。/モノローグ「地上から、亡魂が昇ってくる」/「ふ…ふ…」
- 3/膝もとへ流れ着く老農夫の魂、手元アップ。/なし/なし

## P3
- 1/魂に触れるサットヴァの掌、流れ込む記憶のフラッシュ(田、娘の婚礼、鍬)。/モノローグ「触れれば、生きた歳月のすべてが流れ込む」/コマ内を回想トーンで分割。
- 2/目を伏せるサットヴァのバストアップ。/「——案ずるな。田は、残った者が継ぐ」/なし
- 3/両掌で魂を包む。/「涅槃」/小さく「ふ…」

## P4
- 1/魂が白く澄み、円光の環をくぐって昇る。縦長コマ。/なし/「すぅ…」光の尾を長く。
- 2/胸を押さえるサットヴァ。/モノローグ「務めを果たすたび、胸の奥に小さな喪失がある」/なし
- 3/白く霞んだ回想コマ(朝餉の膳が霧に消えている)。/モノローグ「涅槃は、術者の記憶を——人であった頃のぬくもりを、供物に取る」/なし

## P5
- 1/水鏡を覗くサットヴァ。映る顔。/モノローグ「生前の己の顔を、俺はもう覚えていない」/なし
- 2/形なき古き神々の気配(光の靄)。/神々「人の記憶は、神には枷」/なし
- 3/掟の文字を背景に目を閉じるサットヴァ。/神々「天に昇りし者は、人であった頃の名を捨てよ」/なし

## P6
- 1/夢の景色。戦火の村、幼い手が袖を握る。顔は描かない。/モノローグ「夜ごと、夢を見る」/回想トーン全面。
- 2/袖を握る小さな手のアップ。/モノローグ「この手のぬくもりだけが、消え残っている」/なし
- 3/覚めた目のアップ。/モノローグ「——あれは、誰だったのか」/なし

## P7
- 1/昇ってくる魂の群れ。中に黒く煤けた魂が混じる。/モノローグ「近ごろ、魂の質が変わった」/「ざわ…」
- 2/煤けた魂に触れ、顔をしかめる。/魂の声(ギザ吹き出し)「焼かれた」「弔われなかった」/「チリ…」
- 3/西の空、灰色の翳り。ロング。/モノローグ「地上で、何かが起きている」/なし

## P8(見開き想定・山場)
- 1/夜の池が波立ち、消え入りそうな幼い魂が昇ってくる。/なし/「ぽ…」
- 2/掬い上げる両手。流れ込む幻影=燃える村、灰の風。/なし/「ゴォ…」
- 3/大ゴマ:魂が押しつけてくる記憶。幼い声の吹き出しを大きく。/魂「さよ、さま……さよさまの、ように……」/サットヴァの見開いた目を挿入コマで。

## P9(引き)
- 1/震える指先アップ。/モノローグ「小夜——なぜ、その名を俺は知っている」/円光「カタカタ」
- 2/明滅する魂。/魂「たすけて……まだ、みんな、はいのなかに……」/なし
- 3/大ゴマ:夜空に鳴る警めの鐘。伽藍のシルエット。/モノローグ「天界の夜に、鐘がひとつ、低く鳴った」/「ゴーン——」次話へ引き。
