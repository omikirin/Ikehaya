# ネーム 第三話 灰の帝(全10ページ)

## P1
- 1/灰の渦がゆっくり人がたに編み上がる。縦大ゴマ。/なし/「ゾゾ…」
- 2/王衣のような灰の襤褸、眼窩の鈍色光。全身像。/モノローグ「死者ではない。弔われなかった嘆きだけが、凝り固まったもの」/「ミシ…」

## P2
- 1/灰帝アップ。多重の声の吹き出し(老人・女・童の声を重ねる)。/灰帝「ひかり……よこせ……われは、灰の、帝……」/なし
- 2/対峙するサットヴァ、一歩前へ。/サットヴァ「渡してやろう。そのために降りた」/なし
- 3/灰帝の巨躯が揺れる。/灰帝「いらぬ……われらは、すてられた……名を、よばれなかった……」/「ザワ…」

## P3(見開き・戦闘開始)
- 1/大ゴマ:灰の津波が四方から殺到。/なし/「ゴォォッ」
- 2/円光を引き外し盾に変えるサットヴァ。/なし/「シャン!」
- 3/盾が灰を白光で押し返す。接触面が曇る描写。/モノローグ「輝きが、薄皮のように剥がれていく」/「ジュゥ…」

## P4
- 1/灰の奔流の狭間、社の軒下。/なし/なし
- 2/位牌の束を抱いてうずくまる少女・時雨。目だけ光を見上げる。/なし/「ハ…」
- 3/灰帝の眼光が少女を捉える。/灰帝「あたたかい……いきている……なげきの、たね……」/「ギョロ」

## P5
- 1/振り上げられる鎌状の灰の腕。/なし/「ブォ…」
- 2/駆けるサットヴァ、忍の体さばき。スピード線。/モノローグ「考えるより先に、体が動いた。神ではなく——忍の体の記憶だった」/「ダッ」

## P6(見開き・山場)
- 1/大ゴマ:少女の前に割り込み、盾で灰の腕を受け止めるサットヴァ。地が割れる。/なし/「ドォン!!」
- 2/軋む骨、食いしばる歯のアップ。/モノローグ「神となって初めて知る、地上の痛みの重さ」/「ミシ…」
- 3/短く言う。/サットヴァ「——目を閉じていろ」/なし

## P7
- 1/盾を投げ上げ、宙で環に戻る円光。/なし/「シャァン」
- 2/環の中心へ両手を差し入れ、灰帝を見据える。縦大ゴマ。/サットヴァ「涅槃」/なし
- 3/白い静けさが環から放たれる。爆発ではなく夜明けのような光の面。/モノローグ「それは、夜が明けるときの静けさに似て」/「……」無音演出。

## P8
- 1/灰帝の表層から青白い魂が幾十も昇る。/なし/「ふ…ふ…」
- 2/怯える灰帝。/灰帝「……けすな……われを、けすな……!」/「ズズ…」
- 3/灰の裾を引き摺り山へ退く巨躯。灰がやむ。/なし/「……」

## P9
- 1/膝をつくサットヴァ。痺れた掌。/なし/「ガク…」
- 2/記憶を浚う演出:夜営の火、袖を握る手…そして白く塗り潰された顔。/モノローグ「小夜の、顔が——ない」/なし
- 3/灰の上に落ちる呟き。/サットヴァ「おまえの顔を、俺は、もう……」/なし

## P10(引き)
- 1/背後から声。振り向くサットヴァ。/時雨「——あの」/なし
- 2/位牌を抱いて立つ時雨。灰に汚れた頬、まっすぐな瞳。/時雨「その光……曾祖母さまから、ずっと聞かされてきた……」/なし
- 3/大ゴマ:時雨の問い。サットヴァの見開かれた目を対置。/時雨「あなたは……早蕨さま、ですか」/「ドクン」次話へ引き。
