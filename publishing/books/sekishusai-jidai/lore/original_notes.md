# 本作独自解釈(二次創作オリジナル要素の列挙)

公式で null の profile/relations を埋める部分は、すべて本作オリジナルの解釈である。

1. 石舟斎の来歴: 若き日は「伊賀一の斬り手」と呼ばれたが、ある夜、抜き身の速さゆえに斬らずともよい相手を斬ってしまい、以後「抜かぬこと」を修行の芯に据えた——という過去は本作の創作。
2. 大典太の解釈: 「病魔を払う霊剣」という史実の大典太光世の伝承を借り、本作では「鞘のうちにあるだけで邪気を鎮める刀」とする。抜かぬことに意味がある刀、という位置づけは本作独自。
3. 弟子・千代(ちよ): 本作オリジナルキャラ。伊賀の炭焼きの孫娘。腕は立つが「斬れない」ことを恥じている少女。公式キャラではない。
4. 敵・野盗くずれの浪人「鵺森(ぬえもり)」一党: 本作オリジナルの敵。公式キャラを悪役にしない方針に従う。
5. 山寺の情景、石舟斎の庵、里外れの街道などの舞台はすべて創作。
6. 時代設定: シーズン2(平和な現代)の伊賀の里。平和な時代ゆえに「剣の要らぬ時代に剣を教える意味」を主題化するのは本作の解釈。
7. 石舟斎の老いと病(冬ごとに重くなる咳)は本作の創作。効果・強さは公式より盛らない: 無刀取りは「相手の刀を素手で制する技」の範囲で描き、超常の力にしない。
