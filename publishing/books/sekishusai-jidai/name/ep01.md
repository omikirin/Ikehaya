# ネーム 第一話 庵の客(全10ページ)

## P1(扉)
- 1/大ゴマ。杉山の裾の庵を遠景で。朝靄、細い囲炉裏の煙/モノローグ「伊賀の里の外れに、一軒の庵がある」/演出: 静寂。効果音なし
- 2/軒下に几帳面に積まれた薪のアップ/なし/しん…

## P2
- 1/囲炉裏端の石舟斎。老いた横顔/モノローグ「石舟斎、七十を幾つか越えている」
- 2/壁に掛かる大典太の鞘のアップ/モノローグ「里の誰も、この老人が刀を抜くところを見た者はない」
- 3/口元を押さえ小さく咳をする手/ゴホ…(小さく)

## P3
- 1/戸を叩く音。振り向く石舟斎/とん、とん
- 2/戸を開けると千代。頬が赤い。背に木刀/千代「弟子にしていただきとう存じます」
- 3/霜の土に手をつく千代の手のアップ/なし

## P4
- 1/石舟斎、無表情に見下ろす/石舟斎「わしは弟子を取らぬ」
- 2/閉まる戸/ぴしゃり
- 3/戸の外、座り続ける千代のシルエット。日が傾く/モノローグ「気配は、夕方まで消えなかった」

## P5
- 1〜3/小ゴマ連続: 翌朝も来る千代/断る石舟斎/湯漬けの椀を黙って戸の外に置く手/なし
- 4/雪の水で洗い伏せられた椀/モノローグ「行儀は爺さま仕込みか」

## P6
- 1/三日目の夕。戸を開け見下ろす石舟斎/石舟斎「なぜ剣を習いたい」
- 2/顔を上げる千代。目の縁が赤い/千代「あたしは、斬れないのです」
- 3/石舟斎の目のアップ。わずかに見開く/なし

## P7
- 1/回想(千代)。山道、乱破くずれの影、鉈に掛けたまま動かない千代の手/千代(語り)「腰の鉈を、抜けなかった」
- 2/背負い籠で孫を庇う与平/千代(語り)「爺さまが庇ってくれて」
- 3/拳を握る千代/千代「あたしは強いはずなのに、斬れない。それが恥ずかしくて」

## P8
- 1/長い沈黙。鳶が一声/ぴーひょろ…
- 2/石舟斎の内心。目を伏せる/モノローグ「治すべきは、そちらではないのだがな」
- 3/石舟斎「帰れ。わしが教えられるのは、おまえの望むものではない」

## P9
- 1/夜。囲炉裏の残り火と大典太/モノローグ「抜かぬことを教える剣の道など、あるものか」
- 2/寝つけぬ石舟斎の背中/モノローグ「あるとすれば、わし一代で仕舞いにするはずのものではなかったか」

## P10(引き)
- 1/大ゴマ。明け方、雪。戸を細く開ける石舟斎の視点——雪の積もる庵の前に、肩に雪をのせ木刀を抱いて座り続ける千代/なし/演出: 無音。雪だけが降る
- 2/石舟斎の見開かれた目のアップ/次話へ
