# 本作独自解釈(公式未確定部分の創作)

1. 丑の刻参りの解釈: 瀬織の術は「呪いを打ち込む」術であると同時に、名の由来(祓神・瀬織津姫)から「打った釘を逆の手順で抜けば呪いを祓える」両義の術とする。呪いは必ず術者に「移り香」として業を残す、という代償設定は本作オリジナル。
2. ミタマの解釈: 白い人魂状の式(依り代は小さな木偶)。呪いを打つたびにミタマが呪詛の澱を一口ずつ呑んで瀬織を守っている、という設定は本作オリジナル。
3. 「呪い屋」の稼業: 平和なシーズン2の裏で、雑賀の里外れに呪いの依頼が持ち込まれるという設定は本作オリジナル。公式の雑賀クランの気風設定はないため矛盾しない。
4. 依頼人・お澄、髪結いの佐吉、七年前の依頼人一同、杜の老巫女は全員本作オリジナルキャラクター。敵役(呪いの発生源)も本作オリジナルの「合わせ釘の呪詛」であり、公式キャラを悪役にしない。
5. 舞台の「櫟の杜(いちいのもり)」「濡れ紙の宮」は本作オリジナルの地名。
6. 時代設定はシーズン2(平和な現代)。根の国のパスは開かない範囲で、澱・悪霊の気配のみ扱う。
