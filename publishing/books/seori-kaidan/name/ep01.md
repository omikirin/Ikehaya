# ネーム 第1話 丑三つの客(全9ページ)

## P1
- 1/俯瞰・雨夜の櫟の杜全景。黒い木立に一点の灯/モノローグ「雑賀の里の外れに——」/効果音:ザアァァ(雨)
- 2/寄り・社の格子戸。灯が漏れる/「近づいてはならぬと、子どもらは教わる」/演出:濡れた格子の照り
- 3/内観・灯明の芯を切る瀬織の手元。脇に木槌/無音/効果音:ジ…(灯)

## P2
- 1/バストアップ・瀬織の横顔(初お披露目。落ち着いた無表情)/モノローグ「呪い屋、と呼ばれている」
- 2/寄り・木槌の打面。無数の打ち跡/「板を留める槌ではない」
- 3/寄り・白い燐光のミタマ、木偶の依り代/「相棒のミタマは、物を言わない」
- 4/ミタマがふわりと揺れる/瀬織「——来るね」/効果音:ゆら

## P3
- 1/外・雨中を歩く女の足元。泥はね/効果音:ピチャ…
- 2/格子の前で立ち尽くす女の影(顔は見せない)/演出:長い間
- 3/瀬織、目を伏せたまま/モノローグ「引き返した客は、一人もいない」
- 4/女の影/お澄「……夜分に、ごめんくださいまし」

## P4
- 1/格子越しの構図。内と外を格子が分断/瀬織「格子は開けません。そのままで」
- 2/お澄の口元のみ/お澄「人を、呪ってほしいのです」/効果音:ドッ(雨足強まる)
- 3/黒ベタに白抜きの回想小コマ3連:簪/嘲笑する男の口元/位牌/お澄(off)「姉の形見を騙り取られ——」

## P5
- 1/瀬織、目を閉じて聞く/モノローグ「恨みの筋書きは、いつも似ている」
- 2/瀬織、目を開く/瀬織「呪いは、あなたが思うようには効きません」
- 3/同・続き/瀬織「打った恨みは必ず残る。相手に——あなたにも」
- 4/格子の外、俯くお澄/演出:雨音だけのコマ

## P6
- 1/お澄、顔を上げる(初めて目元を見せる。泣き腫らした目)/お澄「それでも、お願いします」
- 2/格子下の口から差し入れられる包み/効果音:コト
- 3/瀬織の掌・男の髪一房と木札/瀬織「三晩ののち、丑の刻に打ちます」
- 4/瀬織「効いたかどうか、確かめに来ないこと」

## P7
- 1/遠ざかる足音・雨の闇/効果音:ピチャ…ピチャ…
- 2/ミタマが灯に寄り、木偶の面が瀬織を見る/無言
- 3/瀬織、目をそらす/瀬織「……分かってる」/モノローグ「祓の神の名を負って、呪いを打つ。それがわたしの業」

## P8(見開き山場・前半)
- 1/場面転換・三晩後。雨上がりの商家裏手。月/柱書き「三晩ののち」
- 2/軒下に忍ぶ瀬織。梁を見上げる/モノローグ「打つ前に、道を見立てる」
- 3/瀬織の指先がひやりと濡れる(触れていないのに)/効果音:ゾ…/演出:指先に水滴の描き込み

## P9(引き)
- 1/大ゴマ・梁の暗がりに黒く錆びた古釘一本。周囲の木肌だけ黒く濡れている/効果音:ジット…
- 2/瀬織の見開かれた目のアップ/モノローグ「呪いの釘。それも——」
- 3/袖の中で震えるミタマ/モノローグ「知らぬ筋では、ない」/柱:第2話へ
