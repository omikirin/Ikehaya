# 本作独自解釈メモ(公式未確定部分の創作。公式設定ではない)

本作は CryptoNinja の二次創作小説であり、以下はすべて本作限りの独自解釈・創作である。

1. 「人々の負のエネルギーの象徴」案の採用
   - 公式未確定メモにある「根の国のキャラクター像=人々の負のエネルギーの象徴」案を、本作の存在論的な土台として採用。
   - 本作のシンラは、里の人々が捨てた負の感情(悔恨・嫉妬・恐怖など)が澱として根の国に流れ落ち、それが凝って生まれた存在、と解釈する。

2. シンラの「発明家」解釈
   - 公式プロフィール「発明家としての一面を持つ」を拡張し、シンラは負の感情の澱を材料に器械(からくり)を組む発明家とした。
   - 独自ガジェット: 「澱灯(おりび)」=負の感情を吸って灯る行灯型の器械、「聞き匣(ききばこ)」=人の悔恨の声を採取する匣。いずれも本作オリジナル。

3. シンラの忍術・武器(公式未設定のため本作創作)
   - 術「写し澱(うつしおり)」: 相手の負の感情を自分の身に写し取り、実体化させる術。使うたびシンラ自身の記憶と輪郭が削れる「代償」を設定。
   - 武器: 矩尺(かねじゃく)と發条(ぜんまい)仕込みの工具刀。発明家像に寄せた本作創作。

4. 敵は本作オリジナル
   - 敵「虚(うろ)」: 澱が主を持たぬまま暴走した無貌の集合体。公式キャラを悪役化しないための本作限りの敵。
   - 根の国のボスは登場させず、気配・伝聞のみ(公式未確定のため)。

5. サスラの扱い
   - 公式設定が全て未設定のため、本作では「シンラより古い澱から生まれた無口な同胞」として最小限の創作で登場。

6. 時代設定
   - 封印下の根の国(シーズン2相当の時期)を舞台とし、封印の綻びから里へ一時的に滲み出す、という本作独自の状況を設定。封印自体は破らない(S3の展開を先取りしない)。

7. 岩爺・アトザ
   - 封印の当事者として伝聞・回想でのみ言及。敵対的に貶めず、封印は里を守る正当な行いとして描く。
