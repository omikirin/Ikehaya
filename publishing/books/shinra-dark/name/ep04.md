# ネーム 第4話 写し澱(全10ページ)

## P1
- 1/川幅いっぱいの虚の群れ・ロング/擬音「ずるり…」
- 2/ささがねの糸が張られる・ヤミとヨミの囮/擬音「ぴん!」
- 3/シンラの顔・決意/モノローグ「器械では、足りない」

## P2
- 1/川へ膝まで踏み込むシンラ/擬音「ざぶ…」/モノローグ「冷たさが骨に届く」
- 2/両腕を差し伸べる構え・大ゴマ/モノローグ「写し澱。生まれつき体が知っていた、たった一つの術」
- 3/注意書き的モノローグ小コマ/「写した分だけ、自分が上書きされる」

## P3(見開き級)
- 1/流れ込む感情の奔流・シンラを中心に無数の顔・手・声の断片が渦巻く大ゴマ/文字「届かなかった詫び。言えなかった好意。擦り切れた祈り」/演出: ページ全面を渦に
- 2/隅の小コマ・シンラの目/モノローグ「虚とは、行き場を失った気持ちの吹き溜まりだ」

## P4
- 1/掌に凝る黒い球/擬音「ぎゅ…」
- 2/握り潰す→川面で虚が崩れる/擬音「ぱき」「さあ…」
- 3-4/「写す。潰す。」の反復コマ×2/演出: 同構図の反復でリズムを作る

## P5
- 1/膝が笑う・五体目/擬音「がく」
- 2/視界の端が白む・八体目/演出: コマの端を白飛ばし
- 3/十体目・ふと澱灯を見るシンラ/モノローグ「……これは、何だ?」
- 4/澱灯アップ・留め金/文字「火口の開け方を、忘れていた」

## P6
- 1/硝子をなぞる指・途切れる手順のイメージ(千切れた糸)/擬音「…」
- 2/冷や汗のシンラ/モノローグ「次は、忘れたことにすら気づけないかもしれない」
- 3/それでも腕を伸ばす/セリフ(小さく)「……構うものか」

## P7
- 1/十四体目・腕の中で暴れる球/擬音「がたっ」
- 2/球の中の色・憎しみに見えて、呼び声/モノローグ「分かってしまうことが、この術の一番の毒だ」
- 3/最後の一体が崩れる・岸に崩れるシンラ、同時進行の2コマ/擬音「さあ…」「どさ」

## P8
- 1/目を開けるとささがねの顔・ヤミとヨミが体を引き上げている/セリフ「……馬鹿だね、あんたは」
- 2/ささがね、値踏みでない目/セリフ「写し澱。道理で、あんたの芯は減らないわけだ」
- 3/シンラ「減らない?」

## P9
- 1/ささがね語り・大きめ/セリフ「あたしらは大勢の捨てたものの寄せ集め。あんたは違う。たった一人が、たった一度に捨てた塊から生まれてる」
- 2/罅へ顎をしゃくる/セリフ「同じ味の澱を落とす娘。真新しい位牌。考えられることは多くないだろう」
- 3/去り際の背中/セリフ「澱灯の作り方なら、あたしが覚えてるよ」
- 4/仰向けのシンラ・灰色の天井/モノローグ「忘れても、覚えている者がいる」

## P10(引き)
- 1/頭の中で結ばれていく像・位牌のイメージが大きく/モノローグ「あの位牌。あの子が話しかけて、やめた位牌」
- 2/大ゴマ・起き上がるシンラの全身、膝は震え、目は据わる/文字「俺の核は——あの家の、死んだ誰かの悔恨ではないのか」
