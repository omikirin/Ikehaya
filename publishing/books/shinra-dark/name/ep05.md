# ネーム 第5話 悔恨の主(全10ページ)

## P1
- 1/罅に据えられた聞き匣と覗き筒/モノローグ「確かめる方法は、一つしかなかった」
- 2/円形コマ・お澄の日常モンタージュ(竈・膳・位牌)/演出: 小コマ連続
- 3/隣家の女房に「お澄ちゃん」と呼ばれる/モノローグ「少女の名は、お澄といった」

## P2
- 1/川で小さな虚を退けるシンラ・工具刀のみ/擬音「ざくっ」
- 2/ささがねの口伝えで澱灯を組み直す手元/セリフ(ささがね)「次は留め金を左」/演出: 手だけが先に動く
- 3/シンラの手のアップ/モノローグ「頭が忘れても、手が覚えている。存在とは、どこに宿るのか」

## P3
- 1/七日目の夜・上がり框の隣家の女房と長話の影/演出: 円形コマ
- 2/聞き匣が拾う・匣の底の澱が波打つ/擬音「ざわ…」
- 3/女房のセリフ(匣越しの吹き出し・縁を波線に)「お澄ちゃんのおっかさんも、可哀想にねえ」

## P4
- 1/会話の続き・匣越し/セリフ「最期にね、うわ言でずっと謝ってたんだよ。澄に当たっちまった、って」
- 2/セリフ「手習いをしくじって、ひどく叱って、手ぇ上げてね。仲直りしないまま——」
- 3/セリフ「『堪忍、澄。堪忍』って、それっきり」
- 4/壁に手をつくシンラ/擬音「どく…」

## P5(見開き級)
- 1/大ゴマ・燃えるように疼く核のイメージ。シンラの胸の内に、臨終の床の母のシルエットが重なる/文字「堪忍、澄。堪忍——その言葉の形を、核が知っていた」
- 2/隅の小コマ・シンラの見開いた目/モノローグ「俺は、お澄の母の『堪忍』から生まれたのだ」

## P6
- 1/川べりに座り込むシンラ・ロング・長い時間経過/演出: 空白多め
- 2/円形コマ・肩をすぼめるお澄/モノローグ「あの娘は思い込んでいる。母は怒ったまま死んだ、と」
- 3/シンラの拳/モノローグ「詫びが届いていないのは——俺が、ここに在るからだ」

## P7
- 1/霧の中のサスラ/セリフ(シンラ)「還る、と言ったな」
- 2/サスラ/セリフ「凝りが解けて、捨てた者と場所へ流れ戻る。感情は届くべきところへ届く」
- 3/間・サスラの目が伏せられる/セリフ「凝りから生まれた者は、凝りだ。解ければ、消える」
- 4/シンラの掌アップ/モノローグ「この手が解けて、川に戻る」

## P8
- 1/天秤のイメージコマ・存在と救済/モノローグ「天秤は、思ったより静かに揺れた」
- 2/シンラの独白・顔半分/モノローグ「消えるのが怖いのではない。ここに居たことを、誰も知らないままになるのが怖い」
- 3/反転の気づき/モノローグ「——俺は『届かなさ』から生まれた。なら仕事は決まっている。届かせることだ」

## P9
- 1/川べりに並ぶシンラとサスラ・無言・ロング/演出: セリフなしの1ページ上段
- 2/工房・夜通しの工作、蓮の蕾の發条細工が組み上がる連続コマ/擬音「かち…かち…」
- 3/掌の上で花弁がゆっくり開く/演出: 本作で一番静かなコマにする

## P10(引き)
- 1/夜明け・地鳴り/擬音「ゴ……」
- 2/大ゴマ・封印の壁の前で川そのものが立ち上がる。山のような虚の総体が罅へ膨れ上がる/文字「これまでとは、桁が違う」/演出: 次話への最大の引き
