# 独自解釈メモ(公式の「創作の余白」を使った部分)

公式設定と矛盾しない範囲で、本作が独自に補った設定。

1. **時代設定**: シーズン2末期〜シーズン3の入口。「根の国の封印の綻び」は公式のシーズン3導入(パスが開く)を先取りした二次創作的解釈。
2. **九尾の焔の代償**: 「尾を一枚灯すごとに宇迦自身の記憶を薪にする」は本作オリジナル。公式に術の代償の記述はない。
3. **狐たち**: 宇迦が使役する狐に個体名(白玉・玄)を与えたのは本作オリジナル。
4. **根の国の「影狐」**: 根の国側の敵として出す妖狐は本作オリジナルの雑魚敵。公式の根の国キャラ(ささがね等)は名前を出すのみで直接登場させない。
5. **イズナの失踪**: 物語の起点となる「姉の失踪」は本作の創作。公式にそのような出来事はない。
