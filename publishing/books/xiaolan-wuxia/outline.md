# プロット — 柔よく剛を制す 甲賀拳士シャオラン伝

## ログライン
大陸から甲賀に流れ着いた太極拳の拳士シャオランが、故郷の師父との「拳で人を活かせ」という約束を胸に、水源を狙う剛拳の武芸集団から里を守り、居場所を見つける武侠譚。

## 三幕構成
- 第一幕(1〜2話): 流れ着いた異邦人シャオランの里での日常と疎外感。黒風老一味の襲来で「客人」から「守る側」へ立たされる。
- 第二幕(3〜5話): 一味との攻防で剛に押され、約束(殺さない拳)と守る責任の板挟みに。黒風老の正体=瘴気に憑かれた同郷の拳士と知り、拳の意味を問い直す。巨大化リーリーの代償を払う決断。
- 第三幕(6話): 柔が剛を制す理合の完成。黒風老を「倒す」のでなく「解く」。約束を果たし、甲賀を居場所と定める。

## 全6話
1. **流れ拳、里に着く** — 嵐で漂着したシャオランの回想と、甲賀での居候暮らし。市で暴れ牛を太極拳で受け流し騒ぎを収める(ジャッキー風の椅子と天秤棒の立ち回り)。/ 引き: 山の湧き水が一夜で濁る。
2. **濁り水と黒い風** — 水源の異変を調べに登った山で黒風老一味の先鋒・鉄槌と遭遇。受け流すだけで勝てず水路を壊される。/ 引き: 崖上から黒風老が「三日後、水を貰い受ける」と宣告。
3. **推手の理合** — 岩爺に敗因を問われ「押し返そうとした」と気づく。ネムの絵とリーリーとの推手稽古で「聴勁」を掴む。/ 引き: 約束の三日を待たず夜襲の火の手が上がる。
4. **夜襲、里の轍** — 夜戦。ネムや里の衆と連携し先鋒たちを撃退するが、黒風老の剛拳「崩山」を受けたリーリーが負傷。黒風老の声に故郷の訛りを聞く。/ 引き: 落ちた鉄牌に師父の山門の刻印。
5. **同門の影** — 黒風老は師父の下を破門された兄弟子・洪雷と知る。瘴気に憑かれ剛に呑まれた男。シャオランは殺さずに救うため、代償覚悟で巨大化口寄せを決意。/ 引き: 夜明け、水源の岩場に洪雷が独り立つ。
6. **柔、剛を制す** — 決戦。巨大リーリーが瘴気の獣を押さえ、シャオランは洪雷の剛を四両撥千斤で流し尽くし、推手で瘴気を「発勁で抜く」。倒れた兄弟子を抱き起こし、約束は果たされる。里の祭でシャオランは「甲賀のシャオラン」と名乗る。

## 主役の内的変化
「客人としての遠慮(ここは借り物の居場所)」→「守る覚悟(拳は人を活かすためにある)」→「帰属(約束は故郷に置いてきたのではなく、この里で生き続ける)」。

## 公式整合メモ
- 忍術=口寄せ(リーリー/巨大化)、武器=太極拳のみ使用。盛らない。
- 岩爺・ネム・咲耶は公式の性格・術の範囲。敵は本作オリジナル(黒風老=洪雷)。
- 時代はシーズン2。根の国は「封印の綻びから漏れた瘴気」に留め、公式年表と矛盾させない。
