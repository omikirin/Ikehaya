# KDP 入稿チェックリスト

機械検収 (`validate.py`) が OK になってから、以下を手動で確認して入稿する。

## 入稿前
- [ ] `validate.py` がエラー0で通過
- [ ] Kindle Previewer で EPUB を開き、縦書き・目次・改ページを目視確認
- [ ] 表紙を50%縮小表示しても文字が読める
- [ ] タイトル・著者名の表記が表紙とメタデータで一致
- [ ] 冒頭サンプル(先頭10%)だけ読んでも買いたくなる構成か

## KDPダッシュボード入力
- [ ] タイトル / サブタイトル (book.yaml と一致)
- [ ] 商品説明 (description をHTML整形して貼付)
- [ ] キーワード7つ / カテゴリ2つ
- [ ] KDPセレクト加入の有無 (book.yaml の kdp_select)
- [ ] 価格設定: ロイヤリティ70%は 250〜1,250円 の範囲
- [ ] DRM設定を決めた

## 出版後 48時間以内
- [ ] 実機/Kindleアプリで購入版の表示確認
- [ ] Amazon著者ページ (Author Central) に紐付け
- [ ] `/book-launch` の販促素材を投下 (X告知・LP・ショート動画)
- [ ] カテゴリランキングをスクショ (実績素材にする)
